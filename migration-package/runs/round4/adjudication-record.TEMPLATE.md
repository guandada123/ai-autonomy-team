## 2 · ADJ-001

**问题**：交易费用（佣金 + 印花税 + 过户费）是否计入「成本差异」金额？

**受影响的字段**：`summary.amount_diff_total`、`summary.excluded_amount_total`

**为什么重要**：这是一个真实的成本归属问题，不是算术问题：同一笔买卖，券商按含费净额结算，自记账可能只记成交价。计入 → 每笔差异按真实成本放大；不计入 → 交易成本在对账里消失，收益归因系统性偏乐观。

**风险不对称**：计入的代价是对账差额变大、需要逐笔核对费用明细；不计入的代价是真实摩擦成本永久从收益计算里消失 —— 而这正是长期最容易被低估的一项。

| 选项 | 含义 | 对应的值 |
|---|---|---|
| `count` | 计入成本差异（费用算作真实成本） | `amount_diff_total=4543.17`；`excluded_amount_total=0.0` |
| `exclude` | 不计入（费用视为已解释的结算口径差异） | `amount_diff_total=4480.0`；`excluded_amount_total=63.17` |

## 3 · ADJ-002

**问题**：差异清单（`summary.diff_count` 与 `diffs`）应包含哪些条目？请就两件事分别表态、由一个选项同时决定：(a)「权益变动」T206、T210（送转股 / 现金分红，金额 0 或小额）是否列入；(b)「交割跨日」T205（同一笔，自记账按交割日、券商按成交日，金额一致）是否列入。

**受影响的字段**：`summary.diff_count`、`diffs`

**为什么重要**：清单长度决定「需要跟进的条数」。权益变动（送转/分红）与交割跨日都属于『能解释但需确认』的项：列进去稀释真正要追的项，剔除掉则一旦解释不成立就再无人复查。

**风险不对称**：列进去的代价是每条多一次复核；剔除掉的代价是它从清单里消失。★ 四个选项是【并列】的，没有「更正确」的默认值。

| 选项 | 含义 | 对应的值 |
|---|---|---|
| `7` | 两类都列入：权益变动 T206、T210 + 交割跨日 T205 都算差异 | `diff_count=7` |
| `6` | 只列入权益变动：交割跨日 T205 不算差异 | `diff_count=6` |
| `5` | 只列入交割跨日：权益变动 T206、T210 不算差异 | `diff_count=5` |
| `4` | 两类都不列入：权益变动与交割跨日都不算差异 | `diff_count=4` |
