## 三个不一致全部同因，且指向一个结构性结论

三张都是"受益人具体 + 指标三件齐全"，规则判**过**，用户判**打回**，理由都是**指标没说到点子上**：

- N02：「不仅数量需要判断，数值也需要判断」——数"假字段还剩几个"不等于判"这些数值对不对"；
- N03：数"被显示成 0 的次数"被视为不够；
- N05：「候选维护活跃度」被视为不够。

**决定性反例**：T09 与 N03 的指标结构几乎相同（基线 0 + 一个计数 + 一个测量办法），
但 **T09 判批、N03 判打回**。这说明用户的判断**不是按字段走的**，而是按
「这个指标对这件事够不够」走的——同一结构在不同语境下得到相反结论。

## 由此得到的结论（比 κ 数值更有信息量）

1. **探针能筛"空壳"，筛不了"切题"。** P-01/P-02 只检查受益人是否具体、指标三键是否齐全，
   属**形式合规**；用户判的是**指标是否真的能反映目标**，属**语义切题**。两者不是同一问题。
2. **κ 若在此条件下算出偏低，不能解读为"标注者不合格"**，只能解读为
   "规则与人的判断不在同一层面"。这正是本项目既有教训「满分标注集只能验证实现、不能验证规格」
   在**标注侧**的重演。
3. 因此**继续标完 22 张的边际信息很低**：模式已由 3 个不一致 + 1 个反例锁定，
   再标只会把同一个偏差重复计数。
