## 四、错误与纠正（按层）

   因只杀父进程时 communicate 卡 120s，孙进程睡醒后自然"已死"。改为同时断言及时返回+寿命 600s。
2. F8 本地绿 CI 红：`os.kill(pid,0)` 对**僵尸**返回成功。三级判据修复，docker Linux 验证+HEAD 反证。

5. F4 夹具作答写成字符串值 → 4 题全"未成票"→ 0.000，**恰好复现历史事故形态**。
6. F4 用例设计错误：单臂必不过准入闸（对题=饱和、错题=全错），PASS 用例必须双臂。

## 八、改进建议（按优先级）

1. **P0 双写者互斥**：同一仓库并行会话提交前 `git pull --rebase` + 提交后 `git log -3` 回读；
   或约定同一时间窗只允许一个会话写仓（用户拍板）。
2. **P1 手写计数生成器化**：交接摘要/实施状态表的计数由 `sync_doc_numbers.py` 类工具生成，
   「交接摘要写完 25 分钟就过期」不该靠人再改一遍。
3. **P2 coverage_gate 样本收编**：5 组正负样本进 make selftest（秒级），门槛脚本获得自己的守卫。
4. **P3 memory 日志按真实日期分文件**，避免 2026-10-27.md 越长越错位。
5. **P4 顺延项**：make_backup / gen_manifest 补测、交接摘要计数更新（随下次收尾）。
