# L-0021 · 全员满分不是好消息，是量程不够

- **日期**：2026-10-24
- **发现场景**：v2 判断类题库第四轮（9 题标签对调，26 题，4 臂）
- **性质**：跨项目通用（评测设计 / 判分 / 实验设计）★ 升级候选 〔🔁auto-promote-2026-11-22·✅已评估·同族覆盖→「全员满分=量程不够」〕

## 现象

同一套 26 题，四臂（1 单席 + 3 席）跑出来：

| 臂 | 一致 | 平衡准确率 |
|---|---|---|
| 单席 | 26/26 | 1.000 |
| 多席 | 26/26 | 1.000 |
| 三席逐席 | 26/26 × 3 | 1.000 |

没有分歧，没有危险失误，单席与多席完全重合。

第一反应是「大家都做得很好」。实际是**这套题测不出任何东西**。

## 根因

这批题的 brief 是判分者我自己写的，而写的时候只放了支持那个历史裁决的事实。
读完材料按常识权衡，必然落在参考裁决上——

> 出题人 = 裁决人 → 题目把答案说出来了。

注意这个偏差的表现形式很容易认错：它**不是**让某一类题系统性变难或变简单，
而是**让所有题同时变简单**，于是差异被压平到 0，看上去像「两者一样好」。

## 教训

1. **「全对」与「全错」同等地无信息。** 判据要能证伪，也要能证真；
   全员满分说明量程上限低于被测对象的实际水平，此时任何「两臂无差异」的结论都不成立。
2. **加题治不了天花板。** 加的是同一种结构的题，天花板跟着铺宽，判据力不变。
   从 12 题加到 26 题、再对调到 13:13，三次都没能拉开差距，因为改的是数量与标签分布，
   没改「谁出题」。
3. **平衡标签只能治标签偏见，治不了天花板。** 这两件事常被混为一谈：
   前者是「答案分布有偏」，后者是「答案太容易」。本轮实测标签对调后动作一致率 36/36，
   证明前者不存在；同时四臂满分，证明后者存在。
4. **预注册判据要包含「太容易」。** 本轮 `DESIGN-v2.1.md` 预先写了「标签一致率 <70% 则假说成立」
   和「全答多数类高于两臂则区分度不足」，**漏了「两臂都满分则量程不足」**。
   漏掉的这条恰好是本轮真正触发的，只能事后补记。

## 怎么用

- 跑任何带判分的对照实验，出结果先看三件事：**上限（是否有人满分）、下限（是否有人全错）、
  基准线（盲目策略得多少）**。三者任何一个贴边，结论都要打回。
- 三者都正常时才谈差异；差异小于单题粒度时不下结论。
- 出题人与裁决人必须是不同来源。做不到时，**不要声称测出了增益**，最多声称「没测出退步」。

## 判别口诀

> 全对 → 换更难的题或换出题人；
> 全错 → 题坏了或判分坏了；
> 只有基准线高于候选时 → 才是真的没学会。
