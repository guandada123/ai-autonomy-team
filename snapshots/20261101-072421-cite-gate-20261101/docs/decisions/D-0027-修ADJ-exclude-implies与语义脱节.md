# D-0027 · 修 `ADJ-001 exclude` 的 implies 与选项语义脱节

- **日期**：2026-10-21
- **决策者**：PM-01（用户指令「做这个」）
- **操作分级**：🟠 中高（**改契约夹具** → 改生成器 → 重建包 → MANIFEST 变）
- **状态**：已执行
- **触发**：`docs/证据链复核-20261021.md` §1.2 席位层扫描（39/86 冲突）

## 缺陷

`ADJ-001` 的 `exclude`（「单侧缺失整笔移出、另册管理」）的 `implies` 是 **380 / 14060**，
而按该选项 label 的字面语义实算应为 **120 / 14320**（T-13）。

**380 不是一个能从任何规则推导出来的数。** 它来自生成器用 `adj001_ids` 求和——那是**注入场景**的单号集合，
而数据里还有自然发生的单侧记录。实测 T-13：注入覆盖 `T100 + 一笔股息` = 14060，实际单侧合计 14320，
漏了第二笔同额股息 `T103`。

**后果**：任何**认真实现该选项**的产出都必然对不上 implies——包括我构造的字面样本。
契约在惩罚正确行为。

## 根因

```python
# 修改前（scripts/make_tasks_20.py）
one_side_amounts = sum((Decimal(next(b2[7] for b2 in bill if b2[0] == t))
                        for t in adj001_ids), Decimal("0"))
```

`adj001_ids` 是「场景注入了哪些单号」，不是「数据里有哪些单侧记录」。两者在 19/20 任务上不等。

## 修法

改为按**全部单侧记录**求和，与 `one_side_ids` 同源，避免两处口径分叉：

```python
one_side_amount = Decimal("0")      # 与 one_side_ids 在同一个分支累加
...
one_side_amounts = one_side_amount
```

## 修好了什么、没修好什么（必须说清）

**修好了**：`exclude` 的 implies 现在**是 label 的必然推论**。

| 样本 | 结果 |
|---|---|
| 构造的字面 exclude（120 / 14320 / fee 0） | ✅ **PASS**（修改前必 fail） |
| 历史 EX-01（13920 / 520，只排非交易性现金流） | 🔴 fail（现在能被正确判为偏离） |

**没修好**：39 处冲突一个没少。因为它们是**另一个缺陷**——

> 选项空间只有两档（全计入 / 整笔移出），而席位实际在表达**第三档**：
> 「只排除非交易性现金流（股息），保留真实买入（新股中签）」。
> r18/EX-01 的 `excluded_categories` 就是「股息入账（非交易性现金流）」——即第三档。

这不是 implies 算错，是**选项太少**。是否加第三档属产品决策，不在本次范围。

## 为什么不是「席位算错」而是「选项不够」

TASK.md 的 ADJ 问句是「单侧缺失条目是否计入」——字面上中签与股息同类，都该一起移出（120/14320）。
但席位的做法（只移股息）在**会计语义上更合理**：中签是真实买入，钱换成了股票，不是"漏记"。
**两种读法都站得住，契约只给了两个选项。**

## 追加判定（2026-10-21 21:1x，用户指令「你来判断」）

### 结论：**不加第三档 `exclude_non_trading`**

### 但我上文「选项空间缺一档」的定性是错的，此处更正

回查契约原文，`TASK.md` §D 写的是：

> 「差异单号」= 两侧在股数 / 成交金额 / 费用 / 日期四列上不完全相同的单号。
> **仅单侧存在的单号亦为差异单号**，差额取该单号在该侧的 `amount`。

**这句话覆盖全部单侧单号，没有给「新股中签」开任何例外。**
股息与中签同属单侧，按契约应一起移出（120/14320）——这正是修好 implies 后能验证的那个值。

因此：

| 我上一轮说 | 更正后 |
|---|---|
| 选项空间只有两档，而语义有三档 | **契约只有一档语义**；「非交易性现金流」子类是席位自己造的，不在契约里 |
| 39 处冲突主体是「选项不够」 | **39 处是席位偏离了明写条款**——机制抓对了，不是契约缺门 |

### 不加档的三条理由

1. **契约已覆盖**：§D 明确「仅单侧存在的单号亦为差异单号」。加档等于为偏离行为改规则。
2. **无真实需求**：29 轮签字 `ADJ-001` **29/29 全是 `count`**，从未有人选过 `exclude`。
3. **会破坏可比性**：改 ADJ 轴基数会让 29 轮签字轴统计失去跨轮可比——本项目已因「45 种类别写法」吃过一次这个苦。

### 这个更正带来的实际收获

39 处冲突从「无法达成」变成「**可判定的偏离**」：
修 implies 之前，即使完全照契约做也对不上（380 不可推导）；修完之后，照做即通过、偏离即报红。
**机制的判据第一次在这个轴上具备了区分力。**
