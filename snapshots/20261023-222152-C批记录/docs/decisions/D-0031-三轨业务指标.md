## 口径修正（过程中实犯）

初版 `metric_error_decisions` 用关键词扫全文，得 **6**；人工核对后确认只有 **2** 是真的。
三类误报：

| 误报类型 | 例子 |
|---|---|
| 「备选方案若采用会全部作废」 | D-0010、D-0011 |
| 「引用了别人被撤回」 | D-0028 |
| 「某类结论作废」的规则句 | D-0030 |

改为两条精确规则后归正：
- **A 自身被取代**：`本决策已被取代` / 状态行含 `已撤回/已作废/已被取代` → D-0016
- **B 被他人点名撤回**：匹配 `撤回 D-00XX` → D-0025（被 D-0026 撤回）

### 第二次修正：自指污染（同日 13:42）

加入本文后，指标从 2 跳到 **3**——因为本文**引用了规则原文**（反引号里的那句话），
被自己的正则当成了"这份决策被取代"。

修法：匹配前先剥掉反引号内的代码片段。修完回到 2。

> **教训**：度量规则与度量对象写在同一个仓库里时，**规则文档会污染自己的度量**。
> 凡是"扫描文本得指标"的实现，都要先排除引号/代码块内的内容。
