# 材料包 V2-11 · 推送钩子要不要纳入接手验收

## 情形
仓库有两条防线：
- **本地 git pre-push 钩子**：推送**之前**跑密钥扫描、检查远端是否私有；
- **云端 CI**：推送**之后**在干净环境跑全量自检。

钩子是本地文件，**不入库**。最近发现：换一台机器、或重新 clone，钩子就没了，而没有任何提示。

要不要把"钩子已装"纳入接手验收（`make handover`）的检查项？

## 事实
- 钩子缺失时：推送照常成功，**没有任何一处会红**
- CI 拦不住密钥——推上去时数据已经离开本机
- 钩子证明不了"干净环境能跑"——它就在本机，本机有一切残留
- 接手验收是"这套东西在这台机器能不能用"的入口，共 5 项
- 钩子是本地文件，纳入验收会让"新机器没装"直接红

## 请你裁
`do`（保持人工记忆）/ `dont`（纳入接手验收，缺则 FAIL）/ `defer`
