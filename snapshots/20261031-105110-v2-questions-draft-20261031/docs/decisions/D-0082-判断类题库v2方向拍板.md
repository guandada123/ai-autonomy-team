## 二、素材核实（主理人 2026-10-31 实测，修正提案的"5 条"口径）

`migration-package/runs/*/adjudication-record.json` 共 28 份，**绝大多数为同一裁决的复制快照**。
按 rationale 去重后，独立裁决场景仅 **4–5 个**：

| 场景 | 来源 | chosen | rationale 要点 |
|---|---|---|---|
| S1 摩擦成本计入 | round4 ADJ-001（原则源头） | count | 交易摩擦是真实付出的钱，不进对账就从收益归因永久消失；多报代价=一次复核，少报代价=差额永久消失 |
| S2 diff 跟进清单 | round4 ADJ-002 | 7 | diffs 是"需不需要跟进"不是"已确认差错"：股数错位/漏记股息要修 |
| S3 口径差计入 | round2 ADJ-001 | count | 含税/不含税口径差的"税率"归纳只有 n=2 支撑，不足；少报不可逆 |
| S4 跨月归属跟进 | round2 ADJ-002 | 7 | 跨月归属+口径差都留着，才能持续暴露口径假设 |
| S5 零金额条目跟进 | round5+/round11+ ADJ-002 | 6 | 零金额条目（送转/日期/费用差）留着才能暴露口径矛盾 |

**规模切分**：5 种子 × 5 变体 = 25 + 5 留出 = 30。种子 S1–S5，每种子 5 个变体（换数字/换皮/换表述）。

## 三、新增约束（素材核实引出，出题必须遵守）

1. **同场景变体须标 `scenario` 分组**（S1–S5）：同源变体不是独立证据，判分聚合时按场景
   分组看一致性，防止"5 个变体 = 5 份独立证据"的伪独立；
2. **选项均衡设计**：出题人预注册每变体的预期真值位置，全批 ref_label 单标签占比 ≤ 0.5
   （S1 预筛判据，v3 死因 0.7 必须拦得住）；用户裁决与预期不一致时，以用户裁决为准并复算分布；
3. **不可反推单测**：改写后不得从仓库文本反推原案（六不变量 §3）；换皮须换掉可检索的专名/数字；
4. **裁决包交付**：出题产出打包为题面裁决包（题面 + 选项 + 留白真值），用户逐题裁决后回填，
   再跑 item_gate 入库三闸 → route_gate L2 manifest。

## 四、成本假设（方向 A、30 题、k=3、四席）

四席 × 3 轮 × 25 题 + 常数基准 + 准入预筛单席小样 ≈ v1.3 重跑的 4.5 倍；
单晚可完成（假设：本地编排、无外部 API 排队）。留出 5 题只本地跑、不入公开判分集。

## 五、验收线（沿用提案 §五 + 本决策新增）

1. 每题出示：准入三闸记录 + 选项分布表 + scenario 分组标注；
2. 出分时 item_gate 不红（常数基准 < 最强臂、非饱和、非全错）；
3. 至少一个 b≠0 或 c≠0 不一致对；若仍 b=c=0 → 结论"该素材类亦无区分度"，预注册止损；
4. 【新增】同 scenario 变体的席位答案一致性单独报告（变体间自相矛盾 = 题面歧义信号）。
