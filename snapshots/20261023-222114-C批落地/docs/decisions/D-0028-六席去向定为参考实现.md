# D-0028 · 六席去向定为「维持为参考实现」，停止在合成任务上继续投入

- **决策者**：PM-01（用户指令「你来判断」）
- **操作分级**：🟡 中（**只定方向，不动代码、判据、夹具**）

- **前置**：`D-0025`（原判断，已被 `D-0026` 撤回）、`D-0026`、`D-0027`、`docs/证据链复核-20261021.md`

## 决策

**走 A：维持现有六席机制。** 不砍席位（否 B）、不换战场（否 C）。

同时定三条边界：

1. **停止**在合成任务上继续做「六席 vs 单席」的实验投入——该问题在现有证据下已无可增加的信息。
2. 机制定位改为：**参考实现 + 判据工具箱**，不是待优化的产品。它的产出是「可复现的机制 + 可机械校验的口径」，
   不是「一个更准的答案」。
3. 复评触发条件（**任一命中才重开**，否则不再讨论）：
   - 真实对账出现第 2、3 个样本，且六席保留的分歧在其中被证明有用；
   - 需要对外交付这套机制（有人真的要在别的机器上跑它）；
   - 单轮成本成为瓶颈（当前 7.4×，但无高频场景）。

## 依据

| 维度 | 证据 | 结论 |
|---|---|---|
| 算术准确性 | n=4：3 平 1 胜（六席胜） | 无优势，但也不是劣势 |
| 判断准确性 | n=1，且单席理由质量不低 | 无证据 |
| **保分歧** | r18/T-13：EX-02 少数派分支（14440/0）正是最终签字口径；单席只给一个答案 | ✅ **唯一被实证的独有能力** |
| 成本 | 实测 ≈7.4×（字节口径） | 低频场景不构成约束 |
| 判据层价值 | `check_consistency` 抓出 26 份里 4 份分桶矛盾；`real_recon` 抓出 Claw 的 `pnl` 幽灵字段 | ✅ **独立成立，与席位数无关** |

## 为什么不是 B（砍到单席 + 判据）

B 省的是一次性 token，砍掉的是**唯一被实证的独有能力**。
且 33 轮证据链的复现价值依赖原架构——砍席位等于让这套历史证据失去参照物。
**在不缺这点成本的前提下，用确定的能力换不确定的节省，不划算。**

## 为什么不是 C（换战场：无标准答案的任务类）

C 需要新任务类 + 新的可证伪标准，等于**另起一个项目**。
而当前没有任何真实样本支撑「主观场景里六席更有用」——那是一个尚未被提出的假设，
用「可能更有用」去开新战场，正是 `D-0025` 犯过的错（拿直觉当依据）。

## 这个决定的代价（如实记录）

- 六席机制很可能**长期闲置**：没有高频真实对账场景，它就只是一份可复现的参考。
- 7.4× 的成本永远收不回——因为根本没有发生。
- **接受闲置**：这套东西的价值不在「被使用」，在「把口径可核对这件事做成了可复现的形式」。
