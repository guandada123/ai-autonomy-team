# L-0044 规则的价值只在「规则未参与命题」的题上可测——否则天花板与循环必然同时出现

**日期**：2026-11-01
**标签**：评测设计 / 天花板效应 / 循环论证 / 消融实验 / 指标选择
**类型**：跨项目通用
**性质**：任何「A 机制（规则库/知识库/prompt/工具）是否提升效果」的评测
**状态**：已实测（`audit/baseline/v2/RESULT-ablation-20261101.md`：5 题消融三方全 5/5、逐题一致；22 题可盲测子集两模型均 22/22）

## 现象

连续四轮实验"触顶"（各臂全对、区分度闸 FAIL）。第一反应通常是"脚手架不够强"，于是加审查角色、加辩论、加二审——**全部无效**：

- 四角色 vs 单席：零不一致对（D-0083）
- 二审臂（R4 可见 R1/R2）：改动率 0/25（D-0084）
- 去掉口径库：5 题消融，无库臂与有库臂**逐题相同 5/5**

## 根因（两条同时成立，缺一不足以解释）

1. **天花板**：题太容易。可盲测的 22 题，DeepSeek 与 GLM 两个家族都是 22/22。
2. **循环**：真正需要规则的那几题，规则正是从这些题的裁决里提炼的。**用题裁规则、再用规则判该题，必然通过**——它不是被测对象，是答案的一部分。

于是形成一个封闭结构：**能测的都满分，需要测的不能测。** 只看任何一面都会误判：只看天花板→"题太简单"；只看循环→"评测不严谨"。

## 判据（出题前先自问三问，任一为否就测不出增量）

| 问 | 否的后果 |
|---|---|
| 题面**故意不给足**条件？ | 给足了 → 无规则也能推，天花板（本次 5 题即此形：三条件全写在题干里） |
| 规则**不是**从这批题（或其同源题）里提炼的？ | 同源 → 循环，必过 |
| 被测机制**改变**了某个可观测中间量？ | 不改变 → 加多少角色都白加（D-0083 的四角色只改流程不改信息） |

## 做法

1. **消融要跑，但先算天花板**：先看现有臂是否已满分。满分就没有增量空间，跑消融是浪费——先算再跑，一分钟省一轮实验。
2. **区分"能力增量"与"可举证增量"**：本次库的准确率增量=0，但"审查结论带条目 id"从 **0/50 → 12/12**。**换指标就测得出，换题源不必。** 指标错了会把有价值的东西判成无用。
3. **命题方式决定结论**：从规则反向出的题（题干写足三条件）天然让"无库也能答对"。要测规则的必要性，题面必须留缺口——**缺口本身就是实验条件**，不是题目缺陷。

## 边界

- 本结论不适用于"规则用于约束生成"的场景（那里规则改变输出分布，可直接观测）。
- 也不证明"规则无用"：只证明**准确率**这个指标在**当前题源**上测不出它的价值。
- 低样本（5 题、单题 20pp）只作方向判断；但三组数据（22/22、5/5、3 题必错）互相印证，方向可靠。
