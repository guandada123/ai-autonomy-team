## 决策

1. **判据物理分层**：`arithmetic`（10 条锚点，自动裁决）与 `adjudication`（3 条判断轴，人类闸门）分文件存放；判断项**不含 `expected`**。
2. **三道 fail-closed 闸门**：算术层路径白名单 / 金额必须 `decimal_equals` / 人类闸门防伪。均 exit 2。
3. **退出码新增 3 = `pending_adjudication`**：未裁决 ≠ 通过。
4. **白名单在 legacy 模式下不强制**（豁免，但写明代价）。
5. **金额全程 `Decimal`**，`load_json` 用 `parse_float=Decimal` 绕过 float。
6. **写入域显式化 + 结构审计第 8 查**，`gen_manifest.py` 加目录过滤与写入域模式。
7. **`scripts/` 为唯一真实源**，`migration-package/` 下同类文件为生成物。
8. **新增 `scripts/regress.py`**：把 11 项验收固化为一条命令，使「回归全绿」成为可复现判据而非口头断言。

## 备选方案与未采用理由

| 备选 | 未采用理由 |
|---|---|
| 单文件 + 每条判据打 `layer` 标签（不拆文件） | 判断项与算术锚点混在一处，无法从格式上阻止判断项被伪装成锚点 |
| 判断项用 `expected` 承载「默认值」 | `expected` 会立刻退化成机器真值，等于回到 F1 |
| pending 返回退出码 0（信息性） | 上游会把「未裁决」当成功 —— 正是要消除的假信心 |
| 整体改名 `03-结构审计八查.md` | 会波及 `_build_xlsx.py`、`outputs/` 等产物，churn 过大；保留文件名只改正文 |
| 独立 `scripts/check_write_domain.py` | 与「单一真实源」相悖，多一份要同步的脚本；扩展 `gen_manifest` 复用现有 sha256 逻辑 |
| 金额改用分单位整数 | 金额来自 CSV/JSON 十进制字面量，Decimal 与字面量一一对应，心智负担更低 |
| 在 legacy 模式也强制白名单 | 会打穿回归第 2 项（见 `.learnings/L-0004`），零收益纯损失 |
| 直接删除越权写入的脚本 | 会销毁 F2 的证据（沿用 D-0002 决定，移入 `evidence-boundary-violation/`） |
