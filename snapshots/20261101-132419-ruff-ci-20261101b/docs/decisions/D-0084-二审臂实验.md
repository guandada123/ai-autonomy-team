# D-0084 · 二审臂实验（四角色能否通过"看到审查意见后改答案"获得增量）

## 一、决策

用户拍板采用 RESULT-v2 的候选 1「二审实验」（2026-10-31 13:06）。目的：检验四角色管线的唯一可能增量路径——作答席在提交答案后可见 R1/R2 的检查发现，并被允许修改答案（写第二份原件，一审原件保留）。

被否决备选：① 候选 2 转型出题质检——与二审不冲突，实验后再定；② 候选 3 重出题库——成本高，先验证机制。

## 二、设计

- 臂 M2（二审）：对每轮 k，新起一个 R4 会话，输入为：修正后盲测题库 ＋ 该轮一审答案（`runs/r4-r{k}.json`）＋ 该轮 R1/R2 报告（`runs/R1-r{k}.json`、`R2-r{k}.json`）。逐题决定是否修改答案，输出 `runs/r4b-r{k}.json`（第二份原件；未改的题沿用一审 verdict，改动记入 `revisions`）。
- 对照臂 S（单席）：沿用既有三轮数据（`single-r{k}.json`），无二审机会。
- R3 veto：沿用各轮既有否决（r1 五题），M2 计分同样剔除。
- 前置修正：V2-20 选项 B 期数笔误已修（24→12 个月），勘误记录见题库 §7；两臂此前均未选 B，对既有数据无影响。

## 三、预注册验收线（跑前锁定）

| 指标 | 判定 |
|---|---|
| 主指标：M2 净赢 = (M2对S错) − (S对M2错) | ≥2 题 → **增量成立**；0～1 → 无增量；<0 → 负增量 |
| 次指标：3 道两臂共同失败题（V2-12/21/24）的纠正数 | 计入主指标，单独报告 |
| 新增错误 | M2 把一审答对的题改错 → 记负向，须逐条说明 |
| 改动率 | `revisions` 题数 / 25 × 3 轮 |

**预声明预期（诚实记录）**：R1/R2 报告的是题面自洽性（数字、口径、选项结构），**不包含用户真值口径**——V2-12/21/24 的失分源于"用户口径 vs 出题人预注册"分歧，检查层无从得知。故预注册预期为 **0 纠正**；若确为 0，结论是"检查层信息量与真值口径无关，二审亦无增量"，而非"四角色无用"。

## 四、局限

单模型（D-0035）；一审数据产生于勘误前（仅影响选项 B 文本）；25 题样本单题=4pp。
