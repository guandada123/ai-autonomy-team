# L-0012 · 闸门呈现假事实，比没有闸门更危险

日期：2026-10-19 ｜ 出处：P10（D-0008） ｜ ★ 升级候选

## 缺陷

人类裁决模板里有一张表，标题写着「不可争议的事实（这部分不需要你判断）」，其中：
- `T103` 写 `2130.00`（实际 1200.00；账单侧两行各 1200.00，模板还用「×2」代替合计）
- `T107` 写 `520.00`（实际 500.00，疑为误取 `raw_total_gap=520.02`）
- 「性质」列写着「口径差」「跨月归属」—— 而 ADJ-001/002 问的**正是**这两类算不算差异

这张表写死在生成器里，夹具一改就不跟，且**没有任何回归项**检查它。
结果：人在错数上、在已被预置归类的框架下签字，还被明确告知「这部分不需要你判断」。

## 谱系

| ID | 形态 |
|---|---|
| `L-0002` | 硬裁判携带被争议判断 → 无法仲裁，只能复述 |
| `F15` | 选项空间不覆盖真实判断 → 只能签出机器答案 |
| `F28` | **闸门呈现假事实** → 判断建立在错误前提上 |

三者的共同点：**机制形式上完整，实质上没有让人的判断进入过系统。**

## 修法（三条，缺一不可）

1. **数值派生**：事实表从 CSV 算，不用写死 id；与 spec 做**双向闸门**（派生集合 ≠ spec 集合 → 拒绝出模板）
2. **观测与解释分离**：表只放可观测原值（金额/日期/行数/含税标记），归类降格为「候选解释」并逐条写 caveat
3. **fail-closed**：任何派生失败 → exit 2 不写文件。**输出一张「看起来权威但可能错」的表，比不输出危险一个量级** —— 签字人不会去核 CSV，他签的正是「这部分我不需要判断」

## 防复发

- 回归第 38 项：fail-closed（夹具缺失 → exit 2 且不写文件）
- 回归第 39 项：事实表逐格 == CSV 派生值；`2130.00` / `520.00` 不得残留
- 回归第 40 项：§1 区间不得含归类词；§1.2 必须明标「解释非事实」
- **通则**：任何「给人看的汇总材料」若由脚本生成，其数值必须与数据源派生比对（进回归），其定性措辞必须与「数据源」分区呈现。手写事实表 = 一定会漂。

## 关联

`L-0002`（硬裁判携带被争议判断）｜`L-0005`（阈值必须与定义式同落盘）｜`L-0010`（选项空间必须覆盖真实判断）—— 四条合起来是同一教训的四个侧面：**闸门的每一层（判据、选项、事实、流程）都可能替人做决定，每一层都要单独钉死。**
