## 决策

**三级权限，按"是否可逆"分流：**

| 层 | 谁 | 管什么 | 是否打断你 |
|---|---|---|---|
| L-auto 自动 | 判据（非 LLM）+ 脚本 | 日常执行、算术终审、审计 L1/L2 | **不打断** |
| L-propose 提议 | AD-01 / 判据 | L3 前提命中、终止提议、价值降级、席位剪枝 | **不打断，但进待裁队列** |
| L-final 终裁 | **人（你）** | ①对 L-propose 的一切；②对任何判据结论的推翻；③不可逆动作 | 仅 ①③ 打断 |

**通过方式：默认通过 + 事后否决（default-allow with veto），唯一例外是不可逆动作。**

| 情形 | 流程 | 时限 |
|---|---|---|
| 日常轮次产出 | 判据通过即生效，你可在 **24h 内否决**并留痕 | 超时视为接受 |
| L3 终止提议 | 只"提议"，**等你裁决**；不裁则继续跑（不停摆） | 无强制时限，但每周汇总一次 |
| 不可逆动作（删除/覆盖/对外发送） | **事前必须你批**，不适用默认通过 | 阻塞直到你回 |
| 你否决任何一条 | 判据结论作废，记录 `human_veto`，当轮标记 `overridden` | 即刻 |

## 备选与未采用理由

| 备选 | 未采用理由 |
|---|---|
| **纯判据终审**（无人介入） | 满足 G2，但失去"最终裁决权"；判据只懂算术，遇到价值判断无人兜底 |
| **每轮人工确认** | 违背 G2；且 33 轮经验已证明"等人签字"会长期阻塞（round2/3 至今未签） |
| **混合（本决策）** | 默认通过保住"无需确认"；否决权 + 不可逆事前批保住"最终裁决"；两者不冲突 |

## 落地要点

1. `params.json` 增 `authority`：`{"default": "auto", "final": "human", "veto_window_hours": 24, "irreversible_requires_approval": true}`；
2. 每条判据结论附 `veto_deadline`；被否决的写 `human_veto`（谁、何时、理由）；
3. V1 验收改为：**连续 5 轮无人工介入且无否决**；新增 **V4：至少一次否决被正确记录并可追溯**；
4. 不可逆动作清单沿用 `forbidden_zones` + 现有 `safe_cleanup --confirm` 约定，不新造一套。

## 回滚

删 `params.authority` 字段、恢复"判据结论即终局"即可；已产生的 `human_veto` 记录保留（历史不回溯）。
