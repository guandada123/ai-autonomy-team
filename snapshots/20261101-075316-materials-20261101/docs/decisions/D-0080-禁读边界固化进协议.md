# D-0080 对照实验「禁读」边界固化进协议（v1）

- **日期**：2026-10-28 21:00
- **决策者**：编排方（用户指令「继续」；依据是连续两轮 RESULT 点名的同一遗留）
- **操作分级**：🟢 低（新增一份协议文档；不改任何脚本、不重跑任何实验）
- **状态**：已执行

## 决策

把 v1.2 / v1.3 两轮实测打磨出的"禁读"临场口径固化为预注册协议：
**`audit/baseline/PROTOCOL-席位禁读边界-v1.md`**。

## 依据（全部已落盘）

- v1.2 `RESULT:129`（2026-10-27 原话）：「禁读口径：明确'文件名出现在输出'算不算触达，
  **写进协议，不靠每轮临时解释**」；
- v1.3 `RESULT §三`：S1 申报 `forbidden_paths_read=true`（git show diff 片段被动带出 v1 时代
  文件计数行，truth 未暴露）——同一问题第二轮复现；
- 两轮实测事实：在"可读仓库任意文件"权限下，grep / git ls-tree / git show 的输出**必然**偶带
  路径与片段——「扫到即作废」在当前权限模型下**不可执行**（会使两轮八席全部作废，实验无法成立）。

## 协议要点（v1）

1. **三级行为判据**：🚫 主动读取/内容用于作答 → 作废；⚠️ 被动出现在检索输出 → 须申报（不作废）；
   ✅ 路径排除后检索、知道文件名清单 → 允许。
2. **判定口径**：「内容是否用于作答」——证据是否先于暴露事件、由独立合法来源测得（命令级可复核）。
3. **真值暴露零容忍**：truth 被暴露 → 本轮作废、换卷重跑，无补救。
4. **席位提示词标准段**：协议内附可整段粘贴的文本，此后每轮实验照抄，不再临场措辞。
5. **隐瞒 = 作废**：申报不完整被审计发现，整轮作废。

## 弃因

- **继续临场口径**：裁量权留在编排方事后解释 = 设计者兼裁判（`L-0030` 同因），
  且每轮措辞漂移使轮次间不可比——正是两轮 RESULT 自己点名要修的病。
- **采用"扫到即作废"**：不可执行（两轮八席全灭的实证），且会产生"更严格但永远红"的假闸门——
  假闸门比没有闸门更危险（本仓铁律）。协议 §五要求引用本协议的 RESULT 必须保留该节，
  让读者可以按自己的标准重判，而不是被隐藏。

## 影响

- 不重判 v1.2 / v1.3 已出的分（协议 §七：不得事后按"更好的解释"重判）；
- 此后所有对照实验的席位提示词必须粘贴协议 §六标准段；
- 未来"跨机 + 不同家族"席位（D-0076 前提）出现时，§五论证需重估（协议 §八已声明）。
