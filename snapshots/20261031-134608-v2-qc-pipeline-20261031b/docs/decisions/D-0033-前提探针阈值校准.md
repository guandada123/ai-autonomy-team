## 一、方法：不用 NLP，用结构化字段

最初设想用关键词识别自由文本，否决了。理由：阈值只能靠感觉调，且**不可证伪**。

改为：提案必须填一张**前提卡**，探针只判字段是否合规。

| 探针 | 字段 | 判定规则 |
|---|---|---|
| P-01 价值 | `beneficiary` | 去掉泛称（我们/团队/系统/流程/机制…）后**有效字数 ≥5** |
| P-02 度量 | `metric` | 必须含 `name` / `baseline` / `method` 三键且非空 |
| P-03 代价 | `do_nothing_cost` | 必须含 `description` / `comparable`，且 `comparable=true` |

好处：同输入必同输出；误报能定位到具体字段，而不是"模型觉得不对"。

## 五、局限（必须写清）

1. **自己出题自己判分**：标注集由我构造，20/20 很可能偏乐观，不代表真实提案上的表现；

3. **中文字数不是语义**：「有具体主体」用字数近似，长而空的话仍可能通过。
