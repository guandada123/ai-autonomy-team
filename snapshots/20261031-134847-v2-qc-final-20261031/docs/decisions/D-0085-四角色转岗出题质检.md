# D-0085 · 四角色转岗：从答题侧下线，前置为出题管线质检层

## 一、决策（2026-10-31，用户拍板 RESULT-v2 候选 2）

四角色（R1 数据核查员 / R2 逻辑审查员 / R3 风险裁判 / R4 独立分析席）**不再挂在答题侧**，改为出题管线的质检层。依据：四代实验（v1.1–v1.3、v2 一审、v2 二审）一致证明答题侧多重实例无增量；而本轮 R1/R2 实际产出三类可用质检结论（题面矛盾、选项结构泄漏、模板化）。

被否决备选：① 继续在答题侧加席位（成本 6 倍、四代零增量）；② 检查层接口径库（候选 1，成本高、需先建口径库，保留为下一轮候选）。

## 二、职责变更

| 角色 | 原职责（答题侧） | 新职责（出题质检） | 交接产物 |
|---|---|---|---|
| R1 数据核查员 | 题面事实核查 | 命题自洽：跨题设定一致性、数字合计、规则与选项冲突、口径歧义 | `r1: {qid, verdict: corroborated/contradicted/unverifiable, detail}` |
| R2 逻辑审查员 | 选项结构审查 | 结构泄漏：互斥完备、字面可反推、篇幅/元话语线索 | `r2: {qid, type: ambiguity/non_exhaustive/reverse_inferable/none, detail}` |
| R3 风险裁判 | 程序性否决 | 命题否决：不可证伪、口径不唯一、严重模板化 | `r3: {qid, veto, basis, reason}` |
| R4 独立分析席 | 盲答 | **盲答基线**：冷读作答，测"可解性"（全错=题坏、全对=饱和） | `blind: {qid, verdict}` |

## 三、机检判据（预注册，写死后再实现）

输入 = 命题档案 `dossier.json`（每题：`qid / options{A..D} / correct / r1 / r2 / r3 / blind`），由出题管线产出。

| # | 判据 | 阈值 | 处置 |
|---|---|---|---|
| C1 | R1 判 `contradicted` | >0 条 | **REJECT**（题面事实矛盾） |
| C2 | R3 `veto=true` | 任一 | **REJECT**（命题程序性否决） |
| C3 | 长度泄漏：正确项为最长选项**且**长度 ≥ 其余平均 × 1.3 | 命中 | **REJECT**（可凭字数猜答案） |
| C4 | 元话语泄漏：正确项含「人工复核/闭环/待验证/持续跟踪/持续暴露/跟进」且干扰项全不含 | 命中 | **WARN**（弱泄漏，可接受但记档） |
| C5 | R2 判 `reverse_inferable` 且 C3 同时命中 | 命中 | REJECT（并入 C3 理由） |
| C6 | 盲答基线正确率 | <0.3 → REJECT（不可解）；=1.0 → WARN（饱和，交由 item_gate 复核区分度） | 按阈值 |

退出码：0 = 全部通过（可含 WARN）；1 = 存在 REJECT；2 = 输入/schema 错误（fail-safe，空批/缺字段/坏 JSON 一律 2）。

### 判据的实证基线（本轮 25 题实测，作为标定与自检样本）

- C3：**22/25 命中**（长度比 1.62～3.07）——题库当前最大缺陷，机检可一次清出。
- C4：13/25 命中。
- C1：2/25（V2-20 期数笔误；跨题月末 30/31 日体系不一致）。
- C2：r1 五题（ambiguous_gate）——仅作历史样本，转岗后 R3 判据沿用。
- 反证：唯三未命中 C3 的题（V2-12/21/24）恰是两臂全部答"错"的三题——**长度线索正是它们"容易"的原因**，反证 C3 有效。

## 四、验收

- 机检脚本对上述 25 题档案跑出：REJECT 数 ≥ 20（以 C3 为主）、WARN 数 ≥ 10、exit 1；对"人工均衡化改造后的样本"exit 0（正样本必须能转绿）。
- 负样本注入（缺字段/空批/坏 JSON）一律 exit 2。
- 判据本身可证伪：任一条"注入负样本不报红"即判据损坏，阻断合并。

## 五、边界

- 与 `item_gate.py`（答题侧准入：饱和/常数胜出/全错）、`route_gate.py`（路由与偏斜预筛）职责不重叠：本层只看**命题本身**，不看答题结果。
- R4 盲答基线仅作可解性证据，不参与判分。
- **`audit/kit/` 刻意不入迁移包**（2026-10-31 裁决）：包内无 `audit/baseline/` 与 dossier 生成链，
  单带闸门过去是"有闸门无输入"，比没有闸门更易误导；故 `build_package.py` 不映射 `audit/kit`，
  并在映射区注释写明。闸门仅源机可用。
- 单模型局限沿用 D-0035：四角色是同模型不同提示词，质检结论按"维度覆盖"计，不宣称独立性。
