# D-0040 · 停止证明跨模型路由；改为可验证的 Self-MoA

- **日期**：2026-10-22 16:10
- **决策者**：PM-01（三轮实测后判断）
- **操作分级**：🔴 高（放弃一条技术路线）
- **状态**：已采纳

## 决定

**不再尝试证明「子代理是否按指定模型路由」。** 改为主用 **Self-MoA（同模型多采样 + 聚合）**。

## 依据：五条路全试过了

| # | 手段 | 结果 | 结论 |
|---|---|---|---|
| 1 | 自报模型名 | 报了指定名字 | ❌ 可能是复述，不可信 |
| 2 | 不存在模型名反证 | **照样返回** | ❌ 失败静默回退 |
| 3 | 扣费差 | 后台任务**不扣费** | ❌ 信号在被测路径上恒为 0 |
| 4 | 路由记录 | 本会话读不到 | ❌ 无数据 |
| 5 | 同模型 vs 跨模型文本对照 | 同模型 0.554 ≤ 跨模型 0.601–0.675 | ❌ **指标本身无效** |

第 5 条是决定性的：如果换了模型，跨模型文本应该明显更不像；**实测跨模型反而更像**。
说明"文本相似度"这个指标测不出模型身份，**同模型的采样波动就足以覆盖差异**。

## 连带撤回

| 原结论 | 撤回理由 |
|---|---|
| 「GLM 把 7.7 万看成 7 万，算术弱」 | 本轮 GLM 两次都答对 → 那是**采样波动**，不是模型能力 |
| 「三席有分歧 → 三席是不同模型」 | 同模型两次分歧（0.554）比跨模型更大 |

## 为什么改 Self-MoA

| 理由 | 依据 |
|---|---|
| 与"多模型"在本环境**不可区分** | 第 5 条：跨模型差异没超过同模型波动 |
| **免费** | 后台任务不扣积分（D-0038） |
| 有实证支持 | Self-MoA 比标准 MoA 再高 6.6%（Li et al. 2025） |
| 不需要验证路由 | 绕开整个不可观测问题 |

## 落地形态

```
问题 → 同一模型采样 5 次（temperature 默认，不干预）
     → 打乱顺序（防位置偏好）
     → 聚合者（同模型，读 5 份 + 原题，产出最终答案）
     → 记录：5 份原始答案 + 聚合结果 + 分歧点
```

**验收判据**：聚合结果相对"单次答案"，在**可判定的题**上正确率更高，或至少不低；
在**开放题**上，聚合需明确列出「分歧在哪」——这是它相对单次回答的增量。

## 明确不做

- 不再写 `subagents.agents.<name>.model` 配置（配了也无法验证，等于自欺）
- 不再用扣费/自我报告当路由证据
- 不把"多模型"写进任何对外结论

## 回滚

若将来有可观测的路由记录（如换机后 `inspect_agent_routing.py` 能读到 `requestModelId`），
可回到 `D-0036` 的路线并重测；本文不阻止未来重启，只阻止**在没有证据时假装有**。
