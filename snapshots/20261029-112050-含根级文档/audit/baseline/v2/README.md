## 为什么留着而不是删掉

1. 26 条裁决本身是**决策档案**：能查到某件事当年为什么这么定、谁定的；
2. 材料包是新人上手材料：比读 60 份决策记录快；
3. 判分器已被 v3 复用（`--adjudication` 开关）。

## 三条容易误读的地方（读之前先看）

1. **「两臂无差异」不等于「两者一样好」**。这是天花板效应：所有人都满分，差异被压平。
2. **前三轮报过的「差异」已全部降级为噪声**（5/6 vs 5/6、11/12 vs 12/12、25/26 vs 25/26）。
   它们都在天花板附近，不是能力差。
3. **仍成立的一条**：多数票 = 最好的那一席，高于最差的那一席（6 题轮实测 5/6 vs 4/6）。
   它只依赖「聚合不差于最差成员」的结构性质，不依赖题目难度。

## 若要用这批材料

可以做：给人做培训、给新人做判断练习、当决策档案查历史。
不可以做：拿它的分数证明「多席位更好」、拿它给模型评分、把它写进任何决策依据。
