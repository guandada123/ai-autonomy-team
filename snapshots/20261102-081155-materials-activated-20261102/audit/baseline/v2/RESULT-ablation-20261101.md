# RESULT · 口径库增量价值消融（2026-11-01）

**问题**：给作答席口径库，能不能提升它在判断类题上的准确率？

**一句话结论**：不能——而且在当前题库上**结构性地测不出来**。能测的题（可盲测部分）模型已经全对；真正需要库的题（例外来源题）按规则不可盲测。

## 一、预注册（跑前锁定，事后未新增判据）

见 `runs/ablation-prereg.json`。要点：

- 素材：`golden/m004-boundary-5.json` 的 5 道边界题（新行业，由 M-004 反向命制，**非从用户裁决反推**），盲版 `runs/boundary5-blind.json`（已剥离真值，泄漏复检通过）。
- 两臂：**L（有库）**已有数据 xjudge-A/B（GLM-5.3-flash，读口径库手册）；**N（无库）**本轮新跑（deepseek-v4.1-flash，只读盲版，明令禁读任何规则文件）。
- 判据：`N=5/5 → 两臂无差异（天花板），结论=库无增量`；`N≤4/5 → 库有增量，须逐题说明差在哪个条款`。

无库臂 **5/5**，有库两臂各 5/5，**三方逐题完全一致**。命中预注册第一档 → **库在本题集上无增量**。

## 三、把三组数据放在一起，才看得见真正的结论

| 题集 | 能否盲测 | 有库 | 无库 | 说明 |
|---|---|---|---|---|
| 25 题中可盲测的 22 题 | 能 | — | **22/22**（DeepSeek 与 GLM 两个家族都满分） | 触顶 |
| 5 题边界集 | 能 | 5/5 | **5/5** | 无差异 |
| V2-12 / V2-21 / V2-24 | **不能**（例外规则源出该题） | R1/R2 能映射到用户裁决并引对条目 | 两个模型**都答错** | 库唯一真正起作用的场景，却被设计性排除 |

**所以：口径库的准确率增量在本仓库现有题库上不可测，且原因是结构性的——**
- 能测的部分（22 题 + 5 题）两个模型家族都触顶，没有提升空间；
- 需要库的部分（3 道例外题）一旦纳入盲测就是循环论证（用题裁规则、再用规则判该题）。

这也解释了为什么此前四轮实验次次"触顶"：**不是脚手架不够，是题目难度不足 + 测试集与规则源重叠**。

## 四、那口径库到底有什么价值（不吹，只列可核的）

| 价值 | 证据 | 强度 |
|---|---|---|
| **可举证**：审查员能引用条目说明"你违反了第几号口径" | 接库前 R1/R2 共 50 条结论 **0 引用** → 机器审计 50/50 证据不足；接库后两份试点 **12/12 带 id**，审计 exit 0 | 强（有前后对照） |
| **把用户的例外固化成可执行条款** | V2-12/21/24 三次用户推翻预注册 → E-001/E-002/E-003；M-004 经用户 5/5 验证 | 强（用户亲自裁） |
| **回归保护**：规则改动会打红既有答案 | `golden/m004-boundary-5.json`、`golden/mixed-axis-10.json`，均 validated-by-user | 强（机制性） |
| 提升盲判准确率 | 本报告 = **0 增量** | 弱（不成立） |

## 五、诚实限制（必须先说清再看结论）

1. **样本 5 题**，单题 = 20pp，只能作方向判断，不能作显著性结论。
2. **两臂模型不同**（GLM vs DeepSeek）。但两臂都触顶，模型差异不改变"无增量"这一判断。
3. **边界题存在命题偏置**：它们是从 M-004 反向命制的，题干自然把"无未完成核实 / 分类是客观属性 / 逐条保留"三条件写足了。**题面写足条件 → 无库也能推**。这不是意外，是命题方式决定的——也恰好指出"库何时才有用"：题面**故意不给足**条件时。
4. 本实验不能证明"库在真实业务里无用"；只能说"在本仓库这套题上测不出增量"。

## 六、下一步（三选一，成本递增）

1. **停在这里**：把库定位为"对齐工具 + 回归保护"，不再追求准确率增量。成本 0，已可交付。
2. **换指标**：不测准确率，测"可举证率 / 裁决可追溯率"——已有 0/50 → 12/12 的正向数据，扩展样本即可。成本低。
3. **换题源**（唯一能测准确率增量的路）：出**规则未参与命题**的题——用真实业务遗留争议做素材、题面故意不写足口径条件，再用有库/无库两臂比。成本高（需真实素材 + 用户再裁一轮真值）。

**主理人建议**：先做 2（低成本，把已有价值量化清楚），第 3 条只有在你愿意再裁一批真值时才有意义——否则又会得到一堆"两个臂都对"的题。
