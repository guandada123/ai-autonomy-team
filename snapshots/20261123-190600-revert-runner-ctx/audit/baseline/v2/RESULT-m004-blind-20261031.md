# M-004 外推盲验报告（2026-10-31）

> 目的：检验 M-004（归档/转办规则）是**可独立执行的规则**，还是从 6 道旧题反推出来的**过拟合**。
> 方法：5 道全新题（设备维修工单 / 客服投诉 / 保险理赔 / 图书逾期 / 食堂验收，均不复用旧题库行业）→ 作者按规则标注期望答案 → **2 名独立判者**（互相隔离、只见题面+口径库、不见期望答案）盲判。

## 一、结果

| 题 | 场景 | 期望 | 判者1 | 判者2 | 一致性 |
|---|---|---|---|---|---|
| N-01 | 保修期内零金额维修工单 + 逐条归档台账 | D | D | D | ✓ |
| N-02 | 系统缺"受理时间"字段致零时长 + IT 有修复权 | B | B | B | ✓ |
| N-03 | 零赔付但只有口头说明、未调证 | C | C | C | ✓ |
| N-04 | 免罚期内零罚金 + 归档簿（另有 3 条待重算） | D | D | D | ✓ |
| N-05 | 赠品零差异但送货单缺"赠品"字段、账实未核 | A | A | A | ✓ |

- **判者与期望一致：5/5**；**判者间一致：5/5**。
- 位置偏差控制：正确答案分布 D/B/C/D/A（4 个不同字母），选项长度比 ≤1.16，作者在质检中被要求重排过一次。

## 二、这证明了什么

1. **规则可执行**：三名会话（作者 + 2 判者）在不同上下文下，对"该不该归档"得出同一答案，且都能指出命中的条款编号；说明 M-004 的五个条款不是"只有作者懂"的私人语言。
2. **边界可判**：5 题分别踩 ①未完成核实（N-03、N-05）、②结论性定性（N-03）、③压缩载体（各题干扰项）、④无修复权/转出核对义务（N-05）、⑤裸保留（各题干扰项），说明条款能落到具体选项而非只停在抽象层。
3. **位置不泄漏**：答案分布在 4 个字母位上，仍 5/5 判定正确，排除"猜位置"。

## 三、这不能证明什么（关键限制）

1. **不能证明规则符合用户偏好**。期望答案由作者按规则推导，判者也按同一份规则判定——三者同源。**规则内部自洽 ≠ 规则是你要的**。唯一能验证偏好的是：你对这 5 题亲自裁决，看是否与规则推导一致。
2. **不能排除同模型同源**。作者与两名判者是同一模型的不同会话（D-0035 独立性记 0），5/5 一致可能部分来自共享先验，而非规则本身的约束力。要分离这两个因素，需要换模型判定（当前不可得）。
3. **样本极小**。5 题、单一判断轴（归档/转办），不足以覆盖 M-004 在混合轴题目上的表现。

## 四、产物与用法

- `audit/baseline/v2/golden/m004-boundary-5.json`：**回归样例集**（题面 + 期望答案 + 条款映射 + 两名判者答案）。
- 用法：口径库任何条目变更后，重跑这 5 题并核对答案不变；若变化，说明规则被改动（**回归保护，不是正确性证明**）。
- `audit/baseline/v2/runs/new-batch-5.json`（含期望，作者版）、`new-batch-5-blind.json`（判者版）、`judge-1.json` / `judge-2.json`。

## 五、下一步（待用户）

1. **对 5 题亲自裁决**（每题一个字母，5 秒）：这是唯一能把"规则自洽"升级为"规则符合你口味"的动作；若与期望不符，说明 M-004 某条款需要按你的偏好收窄。
2. 若一致：把 M-004 标记为 `validated-by-user`，并作为新题出题的强制质检项。
3. 建议出题时**强制**：每个新批次至少 1 道踩②、1 道踩①的题，防止题库重新滑向"归档万能"。

### N-04 分歧的成因与修正（本轮最有价值的产出）

- N-04 的 B（“已确认免罚”）与 D（“罚金=0”）**实质等价**：都逐条转档、都保留原字段、都把 3 条待重算留在清单，只差分类措辞。
- 用户选 B，而原 M-004(2) 明令禁止“已确认”这类结论性措辞 → **条款过严**。对照 N-01（用户拒绝“按已结案类别”，因为抹掉了“保修期内”这一原因）可知用户真实口径是：
  **分类要保住原因、且已核实；空的结论词与抹掉原因的状态词才该禁。**
- 修正：M-004(2) 由「分类须是客观属性、不得是结论性定性」改为「分类须**含原因或依据且已核实**；禁止未经核实的单方陈述（已说明/已解释）与抹掉原因的空壳状态（已结案/已处理完毕/无差异）」。
- 修正后重判 N-01/N-03/N-04：**3/3 与用户裁决一致**（`runs/rejudge.json`）。
- 附带修题：N-04 的 D 与 B 实质等价属题面缺陷，已把 D 改为“清空免罚原因字段”（违反逐条保留），使其不再并列正确。

### 结论

- **M-004 通过用户验证**（5/5；其中 1 题经条款收窄后对齐），标记 `validated-by-user`，作为新题入库的强制质检项。
- 仍保留的方法论限制：单模型、5 题、单一判断轴；跨模型与混合轴场景未覆盖。
