## 审计发现

1. **重判用的是当前 spec，不是当时那版**——这是选项 A 的实质代价，也是它此前被列为"换尺子"的原因：
   - 判据 **13 → 14 项**：新增 `ADJ-001 → summary.fee_diff_total`；
   - 第 8 项判据改名为「必须声明排除类别**或说明为何为空**」（空数组条款 D-0024 入 spec）；
   - 故 **14/14 与历史的 13/13 不可比**，不能在报告里写成"从 13/13 进步到 14/14"。
2. **`provenance` 刻意写 `post_hoc_derived`，不写 `native`**：本次是事后重建，不是轮内原生产物。
   写 native 会让"这份状态是当时产的"这个断言变成假的——而"一个撒谎的状态文件比没有更危险"。
3. **遗留 warning（未改）**：`W_CATEGORY_NOT_ENUM` —— `excluded_categories` 里的
   「仅费用不符」「股数不符(送转未登记)」不在契约 3.0 枚举内（枚举：单侧缺失/日期口径差/股数不符/
   费用差/重复单号/金额不符）。warning 级、不阻断判分，但影响聚合统计的枚举一致性 → 记入后续待办，
   **本轮不改题面**（改题面 = 换卷）。
4. **两项 open 缺陷同时关闭**：S8-1-LEAK（10-27 两席重跑）与 HASH-CHAIN-BROKEN（本次）。
   `integrity-notes.json` 里两条 findings 的 `status` 已由 open 改 closed，并保留原文不改以存史。
