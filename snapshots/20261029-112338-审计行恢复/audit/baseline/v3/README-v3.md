# v3 · 出题人 / 裁决人分离

日期：2026-10-24 ｜ 触发：D-0063（v2 天花板）、用户「你出题我来裁决」

## 与 v2 的三处差别

| 项 | v2 | v3 |
|---|---|---|
| 参考裁决来源 | 我（出题人兼裁决人） | **用户** |
| 选项标签 | `do` / `dont` / `defer` | **`A` / `B` / `C`**（无字面联想） |
| 指标 | 一致 / 危险失误 / 理由覆盖 / 可裁决性 | 本轮只用**一致率 + 平衡准确率** |

标签改 A/B/C 的理由：v2 实测席位不会"见 do 就选"（36/36 动作一致），
但既然要换裁决人，就顺手去掉最后一个可能引入字面联想的因素。

去掉"理由覆盖"与"危险失误"的理由：这两项要拿**裁决人的理由**当标准。
你的理由我不猜、不代写；本轮不测这两项，比编一份"推测的理由"去测更诚实。

## 题目从哪来

10 道**全部悬而未决**，不选已决定的事。判据：
答案若能从仓库任一文件反推出来，就不算开放题，剔除。

因此本轮不存在"标准答案在仓库里、席位可以去偷"的问题——
仓库里没有答案，只有事实。

## 已知的残余偏差（不假装消除）

1. **框架偏差仍在**：材料是我挑的事实，选哪些、按什么顺序摆，都会影响判断。
   分离的只是"裁决"，不是"出题"。
2. **题量小**：10 题，单题 = 10pp，正好卡在判据线上。少于 2 题净差不能算显著。
3. **一次裁决**：你只裁一次，无法区分"你的判断"与"你这次的心情"。

## 判据（先写，避免事后找理由）

- 席位与你的裁决一致率 ≥ 8/10 → 席位在这批题上可替代人工判断；
- 6—7/10 → 只能当"列分歧"用，不能当"定结论"用；
- ≤ 5/10 → 席位在这类题上不可用，且应追查是"题太难"还是"材料不足"；
- 若某题**三席一致地与你不一致** → 单列为"系统性分歧"，这是最有信息量的信号，
  逐题复查它到底是我的材料有偏，还是你的裁决有别的考虑。

复算：

```bash
python3 audit/baseline/v2/score_v2.py --adjudication ../../v3/adjudication-v3.json \
    --single audit/baseline/v3/arm-M1.json --seats audit/baseline/v3/seat-S{1,2,3}.json
```

## 常态化流程（Q09 裁 A 后生效）

每轮固定五步，缺一步则本轮结果不入决策记录：

1. **出题（我）**：8—10 道，全部悬而未决；事实两边都写、不给倾向；材料落 `materials/Qnn/brief.md`；
2. **锁题（我）**：作答前把 sha256 写进 `brief-lock.json`。你答完我一个字节都不再改；
3. **裁决（你）**：一行字母，例如 `1A 2B 3C …`；理由可选，不写不影响有效性；
4. **跑席位（我）**：1 单席 + 3 席，隔离目录只读材料；本轮测一致率，不测理由覆盖；
5. **落记录（我）**：`adjudication-v3.json` + `RESULT-*.md` + 决策记录；
   若出现「三席一致地与你不同」，单列系统性分歧并逐题复查。

**你已经裁过的题不再重问**：同一决策第二次进题库等于要求你重复劳动。

**题从哪来**：优先取「真悬着、且答案不在仓库里」的事。答案能从文件反推的一律剔除。
