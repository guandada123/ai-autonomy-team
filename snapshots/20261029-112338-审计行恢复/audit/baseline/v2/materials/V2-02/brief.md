# 材料包 V2-02 · 对照实验的样本量

## 情形
要验证「多个 AI 席位一起评审，是否不劣于一个 AI 单独干活」。
题库已冻结：27 道有效题；单 agent 已测 **20/27（74.1%）**。非劣效 margin = 5pp。

## 两个候选设计
**A 两样本**：两臂各抽一批题（例如各 30 题），比较两个通过率。
按 74% 基线、margin 5pp 估算，每臂需 **n ≥ 59**。

**B 配对**：两臂答**同一批 27 题**，逐题比，只看不一致对：
- `b` = 单 agent 错、多席对（多席赢）
- `c` = 单 agent 对、多席错（多席输）
- 判据 `(b − c) / 27 ≥ −0.05` ⟺ **c − b ≤ 1**

## 已知约束
- 单模型环境：席位之间的**独立性为 0**（开轮 preflight 已如实记录）
- 成本随席数线性增长：27×6 = 162 席输出 vs 27×3 = 81 席输出
- 预算与时间都有限
