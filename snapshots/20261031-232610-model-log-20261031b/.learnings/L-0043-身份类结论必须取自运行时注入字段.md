# L-0043 身份类结论必须取自运行时注入字段——自述与推测都不算证据

**日期**：2026-10-31
**标签**：可观测性 / 证据分级 / 环境变量 / 自我报告 / 结论标签
**类型**：跨项目通用
**性质**：一切「当前运行的是哪个模型 / 哪个版本 / 哪个配置」类结论（模型家族、构建版本、部署环境、灰度分组）
**状态**：已实测（2026-10-31 用两个子代理探测本机子代理实际模型，见 `audit/baseline/v2/RESULT-xmodel-20261031.md` §四点六）

## 场景

报告里写了「跨模型盲验」。但「子代理是否跟着切换到新模型」这件事，主理人在会话内**看不到**——子代理不返回模型标识，会话日志目录又被权限策略挡住。于是产生两种坏做法：

- **自述当证据**：让代理自己说「我是 X 模型」。模型的自我认知来自训练数据，不是运行时事实，答错时无法分辨。
- **机制当事实**：因为「文档说子代理默认继承父会话模型」，就直接宣布「所以已经跨模型了」。机制是**应该发生什么**，不是**实际发生了什么**。

## 正确做法：三级取证，按强度排

| 级别 | 证据 | 强度 | 说明 |
|---|---|---|---|
| A | **运行时注入的字段** | 可作结论 | 环境变量（如 `CODEBUDDY_CURRENT_MODEL_ID`）、系统提示里由运行时拼进去的那句身份行、API 响应体里的 `model` 字段 |
| B | 可复现的对照实验 | 需配合 A | 改变一个输入（如显式指定 `model=lite`），看 A 级证据是否随之变化 |
| C | 自我报告 / 文档机制 / 行为风格推断 | **只能写"待确认"** | 不得写进结论句，只能写进限制段 |

## 本次实际取证链（可照搬）

1. **父会话**：`env | grep -i model` → `CODEBUDDY_CURRENT_MODEL_ID=deepseek-v4.1-flash`（A 级）。
2. **子代理是否继承**：派一个探测子代理，要求它**逐字抄出自己系统提示里那句「本对话由 X 驱动」**，找不到就写 `ABSENT`，禁止猜测。回传 = `DeepSeek-V4.1-Flash` / 精确 ID `deepseek-v4.1-flash`（A 级，与父会话一致）。
3. **对照组**：再派一个 `model=lite` 的子代理。若它换了模型，说明路由参数生效、继承机制真实可切；结果它**仍报同一 ID** → 本机只有一条模型通路，路由参数是惰性的。
4. **结论分层**：
   - 「子代理继承会话模型」→ **已取证成立**；
   - 「跨模型家族」→ 取决于切换前是哪个家族，**机器上无历史记录，仍待确认**。

## 第 3 步的副作用（比主结论更有用）

对照组跑出「切不动」这件事，反过来解释了为什么本批实验做不出真正的双模型对照：**同机只有一条模型通路**。于是「跨模型 5/5」只能降级表述为「跨会话 + 同一模型」，除非能证明切换前的批次用的是另一个家族。**一个用来验证的对照，顺手暴露了实验设计的上限**——这类副产物要主动记，否则下次还会拿同一个标签去写报告。

## 边界

- 只有 A 级证据能进结论句；B 级只能支撑「机制成立」，不支撑「这次就发生了」。
- 拿不到 A 级证据时，**降级标签**比补一句「应该是」便宜得多：改一个词，比日后返工整份报告便宜。
- 探测子代理的提示词必须写死「找不到就写 ABSENT，禁止猜测」——否则它会用自我认知填坑，污染取证。
