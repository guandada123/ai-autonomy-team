## 二、主结果（预注册指标）

| 指标 | 单席臂 | 四角色臂 | 常数基准（全 A） |

| 平衡准确率 | 0.896 | 0.896 | — |

- **两臂不一致对 = 0 : 0**：三轮作答逐题完全一致，净输 0 → **非劣效成立**（验收线 ≤1）；**增量未成立**（<2）。
- 四角色臂与单席的全部差距来自 R3 veto：r1 否决的 5 题恰好 R4 全部答对，被剔出计分后拉低 pass^1/3。**在本设置下否决机制是纯负贡献。**
- item_gate 六臂全部 0.880；**饱和题 22/25**（准入判定 FAIL：先修题再谈分数）；"全错"3 题 = V2-12/21/24——**正是用户推翻预注册的三题**，all_wrong 闸正确引导"查真值"而非"怪模型"。

## 三、结构性发现（比分数更重要）

1. **答案冻结设计下，四角色检查层对作答零影响（按构造成立）**：R4 独立作答、答案冻结、辩论跳过 → 臂 M 的 R4 与臂 S 同分布，三轮逐字一致。本轮实验检验的只是"检查层 + veto"的附带产出，不是"四角色答题"。
2. **R3 裁决轮间方差极大（5 → 0 → 0）**：同一批 R2 类发现（"暂不计入"立场拆分到两个选项），r1 被从严解释为 ambiguous_gate 否决，r2/r3 按"不确信即 false"放行。**程序性否决的一致性是四角色机制最薄弱环节**——裁判比作答席更不稳定。
3. **题库触顶第四次复现**：22/25 饱和 + 三轮作答零漂移（pass^3 = pass^1）→ 本题库对当前模型无区分度，"靠运气"检测在本题库上失灵。四代题库（v1 → v1.3 → 前提卡 → v2 判断题）全部触顶。
4. **R2 质检发现真实可用**：题库高度模板化——正确项普遍"自带论证、篇幅显著长于干扰项"、关键词（人工复核/闭环/待验证）跨题可模式识别；V2-20 选项 B 期数错误（24 个月 vs 题面 12 个月）为出题人笔误。**R1/R2 的实际价值是题库质检，不是答题增益。**

## 四、结论（按预注册验收线）

**答案冻结版四角色管线在判断类题上无增量**（非劣效但零增益，且 veto 有负贡献）。检查层的真实价值在题库质检环节。
