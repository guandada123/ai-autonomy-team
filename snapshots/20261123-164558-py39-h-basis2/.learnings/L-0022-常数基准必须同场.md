# L-0022 · 常数基准必须与候选同场；模型在三选一里偏向「折中」

- **日期**：2026-10-24
- **发现场景**：v3 首轮（10 道开放题，参考裁决由用户给出，1 单席 + 3 席作答）
- **性质**：跨项目通用（模型评估 / 方案选择 / 决策支持）★ 升级候选 〔🔁auto-promote-2026-11-22·✅已评估·同族覆盖→「常数基准须与候选同场」〕

## 现象

| 臂 | 与用户裁决一致 |
|---|---|
| 单席 | 5/10 |
| 多席（3 票） | 5/9 |
| **全答 A（不看材料）** | **7/10** |

一个不看材料的常数，赢过单席和多数票。

原因不神秘：用户的 10 个裁决里 7 个是 A，而三个候选里 A 恰好是「保持现状 / 做彻底」那一侧。
席位偏好另一侧，于是输给常数。

## 教训一：基准不跟候选同场，就会把「不如常数」看成「差不多」

前几轮我都报「多数类基准线」，但只在报告里做参照，没当胜负判据。
这次它直接翻盘：**0.700 > 0.556**。

规则：任何带判分的对照，**常数策略必须作为一条臂参与比较**，与候选同一批题、同一判分：

- 全答多数类（测是否只是跟随分布）
- 全答第一项（测是否存在位置偏好）
- 若两者之一高于候选 → 候选没有学到东西，只是学了一个偏置

## 教训二：三选一里，模型偏向中间那个

参考分布 A7 / B1 / C2；四臂选 C 的次数是 5—6 次/10。

C 在每道题里都是「加个轻量机制 / 折中方案」：写进待办、每月导出、双份报告、移入 archive。
四臂**一致地**选它，而用户四次都选了「不动」或「做到底」。

这不是随机噪声：四臂在分歧题上引用的事实全对，分歧只在**代价怎么算**。
模型把「新增一套机制的运维成本」算得重，把「已有资产的可选价值」算得轻。

推论：**三选一题若中间项是「折中」，参考答案分布会系统性偏离中间项。**
设计选项时应避免「一个正确 + 一个明显错 + 一个折中」，否则测的是折中偏好，不是判断力。

## 教训三：把裁决权交出去，差异才会显形

同一个题集：
- 裁决人 = 出题人（我）→ 四臂全部 26/26，差异归零（L-0021 的天花板）；
- 裁决人 = 用户 → 立刻出现 4 题系统性分歧。

**天花板不是题的问题，是「谁定答案」的问题。** 材料里已经含了出题人的权重，
参考答案自然与材料同向。换裁决人才是唯一有效的解。

## 怎么用

1. 出方案时，先问「如果什么都不做、或永远选第一个，得分多少」；
2. 三个选项里不放「折中项」，除非折中本身就是正确答案；
3. 判断类任务的参考答案只能来自「不在出题链上的人」，模型自评一定同向；
4. 报告里凡写「无差异」，必须同时给常数基准的分数，否则读者无法判断这是「一样好」还是「一样差」。

## 判别口诀

> 先让常数上场。常数赢了，候选就是没学；
> 常数平了，候选就是没差；常数输了，才轮到谈增益。
