5. 回归扩展 10 项（12–21），全部对夹具离线运行，**真实轮次指标不进回归门**。

## 三、备选方案与未采用理由

| 备选 | 未采用理由 |
|---|---|
| `DIFFSET` 用 `wide/medium/narrow` 别名 | `6` 与 `5` 的选项 id 多重集完全相同（都是 `as_diff`+`not_diff`），只能靠数值区分；引入会随数据漂移的别名等于埋雷 |
| 保留 ADJ-002/003 为两个独立轴 | 数值重合、无法反推，保留只会产出两个测不准的量 |
| 「无独立证据」= 无证据指针 | **与席位契约冲突**：契约要求 `evidence ≥1`，故合规席位永不满足该子句，**机制永不触发**。已改为「指针是否被共享」 |
| 翻边率分母取席位数 / 轴数 | 席位数 → 弃权席位被算成稳定或翻边；轴数 → 一席改变即整轴翻边 |
| `restart_round` 就地重跑 | 同样输入与顺序会复现同样翻边，等于没有干预 |
| 把「反对意见」也算新证据 | 任何一轮都必然「有新证据」，`idle_detection` 永不触发，机制失效 |
| 不合格席位「挪走」 | 会销毁证据（违反分歧守恒），且让工具替人做判断 |
| `seat_check` 抽共享模块复用 `verify.py` 的 helper | `verify.py` 的 Decimal 语义深度纠缠，抽出会让「冻结的硬裁判」依赖一个会变的模块 |
| `03` 文件整体改名 | 波及 `_build_xlsx.py` 与 `outputs/` 两个既有交付物，churn 过大 |
| 把 `params.json` 搬出包做源侧文件 | 触发 MANIFEST 重建与多处路径引用改写，收益小于代价 |

**S8 证伪条件逐条检查**：
1. 否决了席位但仍引用其 sha256？→ **否**（4/4 valid，`--verify-final` PASS）
2. 所有轴 `comparable` 全 false？→ **否**（ADJ-001 `N=2`、DIFFSET `N=3`）
3. 被 `idle_detection` 终止？→ **否**（`revision_round` 正确豁免）
4. 数字与上一轮一致**且无任何 dissent 边**？→ 数字一致，但**有 7 条 dissent 边**（EX-01 2 条、EX-02 3 条、EX-03 2 条）→ **不构成空转**

> **但须如实指出一个值得警惕的信号**：本轮**立场零变动**、分歧熵 `round_mean=0.0`。
> 三席在两条轴上都全一致。这与项目顶层诊断描述的「共识冒充真相」形态**表面吻合**。
> 我们**不能**据此宣称「辩论无效」——因为一致性也可能来自真实的数据自证（EX-02 本轮正是用
> `ledger.csv` 的 note 列明文推翻了自己上一轮为对立立场构造的 steelman）。但它**也不能**被当作
> 「辩论有效」的证据。**本轮无法区分「收敛到真相」与「共享盲区」，因为翻边率不可算（F7）。**

### 6.1 本轮最有价值的产出：EX-02 的自我推翻

EX-02（异族 `glm-5.1`）上一轮自评论证质量更倾向「甲」（口径差计入），本轮**未改变立场**，
但把 confidence 由 medium **上调至 high**，理由是它发现自己上一轮为「甲」构造的 steelman
**含一处事实错误**：`ledger.csv` 的 `note` 列**明文标注**「口径差异样本1/2」，
使 6% 成为**数据内声明常量**而非 n=2 归纳。

> 这是「对立面席位履职」的产物，**不是从众**：它没有向多数靠拢，而是用数据击破了自己的论证漏洞。
> **但也必须指出**：`note` 列的标注是**夹具作者（我）写进去的**，即这个「数据内声明」
> 在本任务是人为构造的。换到真实对账数据上，`note` 列不会这么慷慨。**该结论不可外推。**
