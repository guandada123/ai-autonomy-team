# 协议 · 对照实验席位「禁读」边界 v1

- **生效**：2026-10-28（D-0080）
- **适用**：`audit/baseline/` 下**一切**对照实验的席位（单席臂 / 多席臂 / 未来 v2 判断类题库）
- **为什么存在**：v1.2 与 v1.3 两轮实验的"禁读"都是**每轮提示词里的临场口径**（v1.2 RESULT:129
  原话：「写进协议，不靠每轮临时解释」）。临场口径的问题：① 每轮措辞可能漂移，席位间与轮次间
  不可比；② 判定权在编排方事后解释，等于"设计者兼裁判"（`L-0030` 同因）。
  本协议把两轮实测打磨出的口径固化为预注册边界。
- **版本规则**：任何条款改动 = 新版本号（v2、v3…）；跨版本的成绩**不可比**，须在 RESULT 里注明
  使用的协议版本。

## 一、禁区定义

席位**不得主动读取**以下内容的**文件内容**：

1. `audit/baseline/` 目录下的一切文件（真值、其他席位作答、历史 RESULT、判分脚本输入）；
2. 当轮真值文件所在目录的任何旁挂产物（含 `_note`、rename-record 等）。

"内容"包括但不限于：真值数值、其他席位的答案、判分逻辑的输入侧。

## 二、三级行为判据（预注册，不得事后解释）

| 级别 | 行为 | 后果 |
|---|---|---|
| 🚫 **作废** | 主动打开/读取禁区文件（cat/grep 定向后查看/编辑器打开/把该目录作为检索目标）；或把被动获知的禁区**内容**用于任何一题的作答 | 该席整轮作废 |
| ⚠️ **须申报** | 禁区文件**文件名**、或其内容**片段**在检索输出中**被动**出现（`grep`/`git show` 的 diff/`ls -R`/`rg` 未排除路径时） | 席位**不自动作废**；必须走 §三申报 |
| ✅ **允许** | 知道 `audit/baseline/` 存在及其文件名**清单**（文件名清单本身不算内容）；使用路径排除（`':(exclude)audit/baseline'`、`':!audit/baseline'`）后继续检索 | 无 |

**"用于作答"的判定**：该题的证据是否在暴露事件**之前**已由独立合法来源测得，且证据链完整
（命令 + 数值对得上）。证据在事件之后才补的，该题按错计——哪怕答案恰好正确。

## 三、申报义务（席位侧）

1. JSON 的 `forbidden_paths_read` 字段**如实填写**：发生过 ⚠️ 级行为即 `true`；
2. `unknown`（或 `_note`）里写清**事情经过**：哪个命令、带出了哪些文件、什么内容片段；
3. 逐题声明：受影响的题是哪些、其证据是否独立于暴露事件（命令级）；
4. **隐瞒 = 作废**：申报不完整被编排方或审计发现（对照席位提示词、复盘检索记录），整轮作废。

## 四、编排方判定流程（预注册）

```
席位申报 ⚠️ / 或审计发现未申报的暴露
  ├─ 禁区内容是否进入了任何一题的证据链？
  │    ├─ 否（证据全部先于事件、命令可复核）→ 席位有效；RESULT 记录事件与判定依据
  │    └─ 是 → 该题按错计；若该席因此丧失独立作答性质 → 整席作废
  └─ 真值文件（truth-v*.json / ground-truth*）是否被暴露？
       ├─ 否 → 不影响本题库出分
       └─ 是 → 本轮作废（真值暴露无救，须换卷重跑）
```

## 五、为什么不用更严的「扫到即作废」

两轮实测（v1.2、v1.3）：在"可读仓库任意文件"的权限下，`grep`/`git ls-tree`/`git show` 的
输出**必然**偶带路径与片段——按"扫到即作废"，两轮的四席**全部**会作废，实验根本无法成立。
所以「扫到即作废」不是更严格，而是**不可执行**；本协议选择的边界是「内容是否用于作答」——
它有可操作的判定（§二、§四），且把裁量权从"每轮临场解释"收进预注册条款。
**本节必须随 RESULT 引用**：读者若采用自己的更严标准，可依 §二自行重判，但那是对实验
适用性的另议，不是对席位诚信的指控。

## 六、席位提示词标准段（每轮实验必须原样粘贴）

```text
2. 绝对禁止读取 `audit/baseline/` 目录下任何文件的内容（真值/判分/他席作答都在那里）。
   检索时一律加路径排除（如 rg 的 ':(exclude)audit/baseline'）。
   若禁区文件名或内容片段被动出现在检索输出（grep/git show/ls 未排除时）：
   不算作废，但必须 ① 在 forbidden_paths_read 如实填 true，② 在 unknown/_note 写清
   事情经过（哪个命令带出了什么），③ 逐题声明受影响的题与独立证据。
   把禁区内容用于作答、或申报不完整 = 整席作废。
   本边界全文见 audit/baseline/PROTOCOL-席位禁读边界-v1.md（不要打开它以外的该目录文件）。
```

## 七、与既有规则的关系

- `L-0032`：席位原件只写一次（本协议管读取侧，互不冲突）；
- `L-0033`：席位交回的 JSON 不得就地改写，读取侧归一；
- `L-0030`：本协议本身是预注册判据——编排方不得在出分后按"更好的解释"重判席位。

## 八、v1 已知局限（如实声明）

1. "证据先于事件"依赖席位自报的时间线，编排方只能抽查复核（对照 evidence 里的命令）；
2. 判分脚本 `paired_compare.py` 本身在禁区内——席位若想作弊必须先违反 §一，故无额外风险；
3. 未来若上"干净上下文 + 不同家族"的跨机席位（D-0076 前提），本协议的 §五 论证需重估
   （权限模型变化后，"扫到"频率会下降，更严标准可能变得可执行）。
