# D-0035 · 单模型环境下的定位：多席位降级，判据与探针保留

- **日期**：2026-10-22 15:17
- **决策者**：用户提供环境事实（原话「workbuddy 除非人为切换否则只有一个模型」）+ PM-01 据此改定位
- **操作分级**：🔴 高（推翻方案的一半前提）
- **状态**：已采纳，配置已改

## 决策

| # | 原设计 | 改为 |
|---|---|---|
| 1 | 「独立性来自**不同模型家族**」，6 席分属 A–E 五族 | **环境只有一个模型**，跨族不可得；多席位＝**同一模型的多视角**，独立性按 **0** 计 |
| 2 | `min_families = 3`，不足则降级 | `min_families = 1`，降级策略改为 **多采样多数票（self-consistency）** |
| 3 | 以「六席辩论」为核心卖点 | **砍掉这个卖点**；保留判据、前提探针、审计流程——这三样不依赖多模型 |
| 4 | V2 判据 = 团队 vs 多采样多数票 | 不变，但预期是「**不劣于**」而非「更优」——同质辩论在期望上不改变正确率 |

## 依据

| # | 依据 | 来源 |
|---|---|---|
| 1 | WorkBuddy 默认只有一个模型，除非人为切换 | 用户 2026-10-22 15:17 |
| 2 | 实测：两个探针小助手都返回 OK，但**读不到任何路由记录** | 2026-10-22 15:10 `inspect_agent_routing.py` |
| 3 | 同质 agent 的辩论在期望上不改变正确率 | arXiv:2601.19921 |

## 这意味着什么（必须说清）

**放弃的部分**：
- 「六个不同厂家 AI 互相纠错」——做不到，除非你每次手工换模型；
- 「多席位更准」——本环境无法验证，且研究上大概率不成立。

**保留的部分**（且更值钱）：
- **判据**：代码说了算，不看模型脸色。今天在真实账本上抓出 4 个静默缺陷，靠的就是它。
- **前提探针**：三个问题把「该不该做」变成可判定的字段，与模型数量无关。
- **审计流程**：分层驳回 + 留痕，一个模型也能做，只是少了「异见」价值。

## 未采用

| 备选 | 为什么不用 |
|---|---|
| 每轮手工切换模型凑跨族 | 成本高、不可自动化；且切换后仍是同一批权重，收益不明 |
| 假装六席五族（保持原样） | 明知只有一个模型还写五族，就是本轮反复批判的"纸面条件" |
| 直接废弃整套机制 | 判据与探针在真实数据上已被证明有效（4 个缺陷），不该陪葬 |

## 落地
