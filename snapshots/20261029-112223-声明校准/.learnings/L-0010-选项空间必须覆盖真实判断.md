# L-0010 ★ 判断轴的选项空间必须覆盖真实判断，否则闸门只能承载机器已有的答案

- **日期**：2026-10-19
- **触发**：准备签署人类裁决记录时，逐条核对 `ADJ-002` / `ADJ-003` 的 `implies`，发现**四选一的自由度是假的**
- **缺陷编号**：F15

## 现象

看起来有 3 条判断轴、8 种组合，实际：

| 组合 | 结果 |
|---|---|
| `ADJ-002=as_diff` + `ADJ-003=as_diff` | 两处都期望 `diff_count=7` → 通过 |
| `as_diff` + `not_diff` | 期望 `7` 与 `5` 冲突 → 必有一条 fail |
| `not_diff` + `as_diff` | 期望 `6` 与 `7` 冲突 → 必有一条 fail |
| `not_diff` + `not_diff` | 期望 `6` 与 `5` 冲突 → 必有一条 fail |

**只有 1/4 能过。** 更关键的是：若人的真实判断是「跨月不算差异、口径差也不算差异」，
语义上应得 **4 条**（T101/T102/T103/T107），而 **4 根本不在选项空间里**。
最接近的可选项是 7 条 —— 恰好是离他的判断最远的那一端。

## 为什么会这样（结构原因）

两条轴共享 `paths_affected`（都是 `diff_count` + `diffs`），而 `implies` 是**静态值**。

> 当两个判断项**共同决定同一个可观测量**，且可观测量的取值是**硬编码**时，
> 它们就不是两个自由度，而是**一个被写死了答案的自由度**。

## 危害

这不是「机器算错了」，而是**闸门失去了意义**：

- 人选机器那个答案 → 通过 → 看起来「人确认了」
- 人选自己的判断 → fail → 看起来「人错了」
- 结果是：**签字只能签出机器已经给出的答案**

「人被要求签字，但实际上没有选择余地」—— 这比没有闸门更糟，因为它**产出信心的假象**。
这与 `L-0002`（硬裁判携带被争议判断则无法仲裁）是同一病的第二种形态：
一个是**裁判**携带答案，一个是**选项空间**不含答案。

## 修法

1. 合并为**单轴四选项**（`7`/`6`/`5`/`4`），让四个语义组合各有一个位置。
2. 选项**由定义式生成**，不手写：
   ```
   decides{跨月: bool, 口径差: bool}
   diffs = 全部差异 − 判为「不列入」的点所含单号
   count = len(diffs)
   断言 count == int(option_id)      # 不等即拒绝出包
   ```
3. 回归加两项：① 四个选项 `len(diffs)==int(id)` 且互不相同；② **2×4=8 组合全部可判定**。

## 通用化

> **在设计任何「让人做选择」的界面（判断轴、审批流、配置项）之前，
> 先枚举「所有真实可能的答案」，再检查选项空间是否为它们的超集。**
> 若某个正确答案无法被表达，界面上有多少个选项都是装饰。

三个自检问题：

1. 我列的选项，是否覆盖了**所有**语义上成立的组合？
2. 这些选项之间是否**互不冲突**（选任意组合都不会自相矛盾）？
3. 若某人选了「最不方便的那个」，系统是判 fail，还是能如实记录？

第 3 问最狠：**「选第三种就报错」的设计，实际上只有两种选项。**

## 代价与边界

- 合并后轴数从 3 降到 2，**信息量没有减少**（旧的 ADJ-002/003 本就只产生一个可观测量）。
- 新增 `W_STANCE_SEMANTIC_CONFLICT`（金额含口径差、清单不含）只作提示。
  它依赖「`excluded_amount_total` 的非零部分只来自口径差」这一显式假设，假设变了判据要改。
- 选项 id 仍用数值串（`7/6/5/4`），**没有**解决「选项 id 与语义脱钩」的隐患 ——
  只因 `derive_stance` 从 `diff_count` 反推，数值串是唯一不引入第二层映射的选择。
