## 一、round1 → 不适用

**依据**：`runs/round1/` 无 `round-manifest.json`（早于清单机制），且它唯一的裁决记录是
`adjudication-record.SELFTEST-PLUMBING-ONLY.json` —— 名字自述是**自检桩**，不是人类裁决。

**弃因**：给它生成 `answer-status.json` 只能得出"pending / fail"两种之一，而这两种都不是
"当时的人类裁决状态"——**用一个自检测桩去生成状态文件，等于制造一个看起来权威的假状态**。
（铁律：一个撒谎的状态文件比没有更危险。）

## 二、round8/9/10 → 维持（不重跑席位）

**依据**：交接摘要已定性——它们是被**前置闸门正确拦截**，不是静默失败；重跑需要多席 LLM，
产物还得重新过锚定与判分，等于再开一轮。

**弃因**：重跑的收益是"补齐终态"，代价是 3 轮 × 多席 + 换卷风险。既然现状是闸门**按设计**拦下的，
补齐终态只改变观感不改变事实。

## 三、26 轮 AD-01 → 不补跑，且**不做抽样验证**（本决策的关键，我改了原计划）

原计划是"先抽样补 1 轮 round14，看有没有新信息再决定批量"。**否决这个计划**，依据三条：

1. **抽样回答不了真问题**。AD-01 的价值前提是模板明写的"由**与 PM 不同家族**的模型担任 + 干净上下文"。
   当前环境只能派同源席位，所以抽样测到的只是"格式能不能产出"，测不到"独立性有没有价值"。
2. **用同源席位做消融会得到假结论**。若我跑一轮同源 AD-01、发现"没有新信息"，
   那结论会是"AD-01 无价值"——但真正的原因是"同源"，不是"AD-01 无价值"。
   这正是本项目自己踩过的坑：**消融必须留对照组，对照两臂必须同信息条件**（`L-0030` 同源推论、
   `D-0070` 校准集无区分力，都是同一个失效模式）。
3. **26 份同源审计意见比 0 份更危险**。它们会让 26 轮"看起来被独立审计过"，
   而独立性实际记 0 —— 假事实比没有闸门更危险。

**若要真验证，先决条件是"不同家族"**：属 v2 / 跨机 agent 的范畴（`D-0068` Reason Network 评估 no-go
也是同一原因：跨机消息层不产生独立性）。前提不具备之前，26 轮一律**维持"结论可用、缺结构审计保证"**，
并在交接摘要里写明"缺 AD-01"是**已知且已接受**的状态，不是待补的债。

## 四、`W_CATEGORY_NOT_ENUM` → 留痕不改

**现象**：round13（「仅费用不符」「股数不符(送转未登记)」）与 round4（「日期差异」「股数差异」）
的 `excluded_categories` 不在契约 3.0 枚举内（枚举：单侧缺失/日期口径差/股数不符/费用差/重复单号/金额不符）。
warning 级，不阻断判分。

**先查了消费方再决定**：`scripts/check_consistency.py`（分桶交叉校验）与 `scripts/canon.py`（类别名归一）
都按**名字**匹配 `diffs[].category`，不依赖契约枚举 → 当前无功能受损。

**弃因**：
- 改 spec 的枚举 = **换尺子**，所有用该 spec 判过的轮都要重判，影响面远大于一个 warning；
- 改 answer 的类别名 = **换卷**（`D-0057`），还要重判、重锚、换锚；
- 因此按 `D-0071` 的口径处理：这是"命名自由度 vs 聚合统计一致性"的**已知取舍**，不是缺陷。
  只在此留痕，等真出现跨轮聚合消费者时再处理。
