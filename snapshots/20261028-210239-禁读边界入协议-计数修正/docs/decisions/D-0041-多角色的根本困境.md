# D-0041 · 多角色的根本困境：能验证的地方不需要它，需要它的地方验证不了

- **日期**：2026-10-22 16:18
- **决策者**：PM-01（四轮实测后）
- **操作分级**：🔴 高（触及机制的存在理由）
- **状态**：已采纳

## 决定

**不再把"多角色/多采样"当作提升正确率的手段。** 它的定位改为：

> **用于"列出可能性与分歧"，不用于"投票定对错"。**

## 依据：四轮实测算出的死结

| 探针 | 任务类型 | 结果 |
|---|---|---|
| 1 | 开放决策题 | 三席全选同一项，无分歧 |
| 2 | 陷阱计算题 | 出现 1 错 2 对，但同模型复跑也这样 |
| 3 | 同模型 vs 跨模型文本对照 | 同模型差异 ≥ 跨模型 → 指标无效 |
| 4 | **Self-MoA（5 采样）** | **5 份完全相同且全对，方差 0** |

第 4 条是决定性的：

> **有标准答案的题，同一模型 5 次采样会收敛到同一答案。**
> 此时"辩论/聚合"没有任何可做的事——纯空转，只多花 5 倍时间。

而反过来：

> **没有标准答案的题，分歧确实会出现，但无法判断聚合是否更好。**

**两端合起来就是死结**：

```
有唯一答案 → 采样收敛 → 多角色无增益（可验证但不需要）
没唯一答案 → 分歧出现 → 无法判定好坏（需要但不可验证）
```

## 这不是"实现不好"，是结构性的

即使换成三家不同模型（若真能换来），结论也一样：
- 算术题：三家都会算对，或错在同一处（共享失效模式，见 arXiv:2605.29800「九评委=2.18 票」）；
- 判断题：三家分歧，但你依然不知道谁对。

## 那这套机制还剩什么价值

**剩下三样，都是真的、且不依赖"更准"**：

| 保留项 | 为什么仍然有用 | 怎么用 |
|---|---|---|
| **判据（非 LLM）** | 代码说了算，能抓人眼漏掉的错——今天在真账上抓出 4 个 | 所有能算的地方都用它 |
| **前提三问** | 挡掉"看起来该做其实没人要"的事 | 立项前必填，答不出就打回 |
| **分歧记录** | 让人看见"原来这里有两种解读" | 输出里列出分歧点，不替人裁决 |

## 明确放弃

| 放弃 | 理由 |
|---|---|
| "多角色更准" | 四轮实测无反证支持；理论上也不成立 |
| "多模型辩论提升质量" | 跨模型与同模型不可区分（D-0039/D-0040） |
| 用投票/多数决定对错 | 有答案时投票多余，没答案时投票是伪确定性 |

## 对人（用户）的实际含义

| 场景 | 该怎么做 |
|---|---|
| 有标准答案的事（对账、算钱、查字段） | 用**判据**，不要问 AI"你觉得对不对" |
| 没有标准答案的事（选方向、定取舍） | 让 AI **列出选项与代价**，你自己拍板；**不要让它投票** |
| 想省时间 | 单次提问 + 判据校验，比五席辩论快 5 倍且一样准 |

## 回滚

若将来出现"既有唯一答案、又能体现多角色增益"的任务类型，可重启评估；
触发条件写死：**同一题、单次 vs 多席，正确率差 ≥10pp 且 n≥20**。达不到就不重启。

## 🔴 2026-10-22 16:25 适用范围更正

**用户质疑**：结论会不会是提问方式造成的。

**自查后确认：会，且很可能是主因。** 详见 `docs/提问设计-复盘与改进-20261022.md`。

四个探针的共同缺陷：
1. **全是收敛型题目**（有唯一答案）→ 采样必然一致，与机制无关；
2. **明令"不要解释"** → 掐掉了唯一可能产生差异的推理路径；
3. **所有席位同一提示词** → 这是"多模型采样"，不是"多角色辩论"；
4. **probe1 背景预设了答案** → 三席全选 B 是我引导的结果；
5. **n=1** → 分不清差异与噪声。

**因此原结论「有答案时零增益；没答案时验不了」应限定为：**

> **在"有唯一正确答案的计算题"上，同模型多采样结果必然趋同——这是采样的定义性质，不是实验发现，不构成实证。**
> **多角色在收敛型题目上是否无增益，无法观测**（观测到的只是同模型多采样，见缺陷 3）；需换开放题重测。
> **在"无唯一答案、需要列全风险与假设"的任务上，尚未测试。**

**重启条件相应更新**：不是看"正确率"，而是看**评分表命中数**——
单次 vs 多采样的命中项**并集**是否有明显差异（见改进文档 §4.4）。

## 🔴 2026-10-22 19:5x 措辞更正（P0-4）

上一版把"5 份采样全同"写成「已证」，这是**同义反复**，不是实证。三层理由：

| # | 为什么不能算证据 |
|---|---|
| 1 | 同一模型 + 同一提示词 + 收敛型题 → 结果趋同由采样机制直接决定，先验可知，无需实验 |
| 2 | 即便观察到趋同，被测的也是**多采样**而非**多角色**（环境只有单模型，见 `D-0036`）；把采样结论搬到"多角色"上是偷换被试 |
| 3 | 本文 §「适用范围更正」自己已承认缺陷 1/3/4 会污染结论，第 99 行却仍用"已证"——前后矛盾 |

**因此本条不构成对"多角色无价值"的证明**，只构成"在收敛题上无法测量"的说明。
真正的结论见 `D-0042`：多角色的价值在**覆盖**（可行动项从 2 项到 11 项），不在正确率。
