# D-0042 · 改进问法后，多角色的价值被测出来了：不是更准，是更全

- **日期**：2026-10-22 16:27
- **决策者**：PM-01（实测）
- **操作分级**：🟡 中（修正对机制价值的判断）
- **状态**：已采纳

## 结论

用改进后的问法（中性事实 + 四角角色 + 强制五段输出）跑 5 席：

| 指标 | 基线（普通问法） | 四角并集 |
|---|---|---|
| 评分表命中 | **3.5 / 5** | **5 / 5**（多出"可证伪条件""自身盲区"） |
| 可行动项 | **2 项** | **11 项** |
| 最终决策 | 停甲乙丙 | 停甲乙丙（**一致**） |

**所以：多角色不改变"选谁"，但显著扩大"还该考虑什么"。**

## 与 D-0041 的关系

`D-0041` 原判"有答案时零增益"，现在限定为：

> **在"求一个正确答案"的任务上零增益（已证）；**
> **在"需要列全风险与选项"的任务上，增益明显（本决策实测）。**

两者不矛盾：猜数不需要五个人，做决定需要。

## 三个具体增量（基线没有、四角有）

| 增量 | 来自 | 为什么重要 |
|---|---|---|
| "停 3 条"这个数字本身是拍脑袋的 | 前提审查 | 可能整个问题问错了——该先建成本度量 |
| 降频替代停掉 | 前提审查 | 更稳的做法，风险小得多 |
| 先查依赖图再动手 | 反对派 | 避免了"停掉日报上游"的不可逆错误 |

这三条都属于**改变做法**级别，不是措辞差异。

## 因此机制的定位（最终）

```
求正确答案 → 单次 + 判据（多角色是浪费）
做判断决定 → 多角色并行，输出"选项 + 风险 + 假设 + 盲区"，由人拍板
```

**多角色不做投票，只做覆盖。**

## 落地：什么任务该开多角色

| 条件 | 说明 |
|---|---|
| 没有唯一正确答案 | 有答案的直接用判据 |
| 决策不可逆或代价高 | 停任务、删数据、对外发布 |
| 需要列全风险 | 越全越好，漏一条可能出事 |

三条同时满足才值得开 5 席；否则单次提问更快。
