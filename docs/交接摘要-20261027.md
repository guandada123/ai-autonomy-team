## 6. 本项目的重要纪律（下轮务必遵守）

1. **不要为「加注释」去改被 sha256 锚定的产物**（本次踩过：`answer-final.json` 被 `answer-status.answer.sha256` 锚定，重写它会让哈希链偏离更远）。留痕放旁挂文件。
2. **改 JSON 历史文件前先看原缩进**（round 内文件是 **1 空格**，不是 2）。用工具默认格式重写会产生数百行无关 diff。
3. **判据要可证伪**：改检查逻辑后必须造正样本（错的 sha、缺失的路径）证明它仍会拦。
4. **「已冻结/已豁免」不是免检**：`problems` 非空时必须仍报 🔴。
5. **门禁绿 ≠ 全绿**：还需单独跑重算（`recompute_watch.py`）。
6. **删文件**：先验证 → 再复制 → 再删源 + 删前确认；`_trash/` 整体不是垃圾。
7. **删前必读**：`.gitignore` 第 5 行原文——「不要把整个 _trash/ 当成可重建的垃圾：删了归档，历史时点就没了」。
