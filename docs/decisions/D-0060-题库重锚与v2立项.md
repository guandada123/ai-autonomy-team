- **状态**：v1.1 已落地并跑通同条件对照；v2 设计就绪、**阻塞在用户裁决**

## 决策

1. **v1 停用**（`D-0059` 已判"不可判定"），改为 **v1.1 重锚版**：26 题，每题带时点与锚点，
   真值可永久重算；`T10` 退役（测量对象已被清理）；
2. 新增 `recompute_truth.py` + `make recompute`：**重算不通过就不许出分**（脚本级硬闸，不是文档要求）；
3. 首次跑**同条件**对照（1 单席 vs 3 席，访问权限完全相同）——这是本轮唯一能解释的 b/c；
4. **v2 判断类题库立项**，但只到"可裁决"为止：参考裁决必须由用户给，模型自评不算参考。

## 同条件对照实验（v1.1）

- **两臂**：单席 `arm-M1.json` vs 三席多数票 `multi-answers.json`
- **条件完全相同**：同一份提示词、同一套访问权限（可读仓库与 `~/Backups/`，禁读 `audit/baseline/`）
- **判分**：`compare_v11.py`，复用 `paired_compare.grade`（口径单一真源），出分前先过重算检查

### 结果（首次可解释对照）

| 臂 | 有效题得分 | 说明 |
|---|---|---|
| 单席 M1 | 22/23 | 唯一失分 Q31（盘上无源） |
| 多席（2 席多数票，第 3 席未回） | 21/23 | 唯一 c 来自 T05 格式差异（`54` vs `"54/54"`） |

`b=0, c=1, 差值 −0.043 → 非劣效成立`；把 `"54/54"` 规范化为 54 后 `c=0, 差值 0 → 同样成立`。
**结论：事实核查题对有据可查的席位列没有区分度（两臂都触天花板），多席聚合在本题库上无增益可测。**

附带：两个独立样本（M1 / S1）在 26 题上**逐项完全一致（26/26）**——事实题上席位冗余度极高。


## 备选方案与未采用理由

| 备选 | 未采用理由 |
|---|---|
| 继续用 v1 跑（不重锚） | 8/27 题今天无正确答案，任何一臂上限 19/27 < 基线 20/27，结论必偏 |
