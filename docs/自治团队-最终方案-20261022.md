### 3.1 席位编制（6 席，理由见 §8-①）

> 📌 **这里的「6 席」是编制口径**（谁产出、谁审、谁拍板）。它与 `角色覆盖度评估` §四的「8 角色」、`D-0044` 的「默认 3 席」不是同一个量，不构成矛盾。
> 三者对照见 `docs/角色映射表-6席与8角色-20261022.md`（含"6 席中 3 个角色无岗位承接"的缺口说明）。

| 席位 | 职责 | 关键约束 | 家族 |
|---|---|---|---|
| PM-01 | 唯一写权限；派发、督促、拍板 | 必须给"决定+依据+风险+回滚"；**不得改写 verdict** | A |
| EX-01 | 事实与数据 | 结论附可执行命令 | B |
| EX-02 | 对立面（既有角色，不新设） | 必须给"若我对，会看到什么" | C |
| EX-03 | 落地与成本 | 必须给"不做"的代价 | D |
| AD-01 | 三层审计 + 终止提议 | 权限 `scope=argument_only`；**不得以流程未定义回避前提** | E 或非 LLM |
| JD-01 | 非 LLM 硬裁判（算术终审） | 只判算术，不判价值 | 非 LLM |

> 🔴 **2026-10-22 15:17 环境更正（D-0035）**：WorkBuddy 默认**只有一个模型**，除非人为切换。
> 所以上表的"家族 A–E"**在当前环境不成立**——六席实际是**同一模型的多视角**，独立性应记 **0**。
> 闸门不再要求 3 个家族（`min_families` 降为 1），但**每份结论必须标注"同模型，独立性为 0"**。
> 降级路径改为**多采样多数票**（self-consistency）：同一问题采样多次取多数，比"六个角色互相说服"更实在。

### 3.2 四阶段流程（R3）

```
① 独立作答（禁止互看）→ per-seat.json（含结论/证据/证伪条件/置信度）
② 匿名交叉（去身份与文风）→ 打乱后广播
③ 结构化辩论（≤ params.debate.max_rounds）→ 只允许：指出事实错误 / 给新证据 / 改立场并说明
   ↳ collapse 监测：立场熵连续下降 2 轮 → 强制中止
④ 聚合：多数票仅作基线，PM 按"证据强度"裁决，算术交 JD-01
```

### 3.3 三层审计（R4，本方案唯一新意）

| 层 | 审什么 | 驳回后果 | 谁判 |
|---|---|---|---|
| L1 结构 | 证据缺失、命令跑不通、字段不符 | 退回重做（记 `attempt++`） | 脚本 |
| L2 论证 | 结论与证据不匹配、样本量不足、口径漂移 | 结论降为"待证实" | AD-01（`argument_only`） |
| **L3 前提** | 该不该做；消失谁受损；指标是否可观测 | **`hit_action=terminate_proposed`**，交 PM 裁 | AD-01 + probe |

**前提探针（3 条起步）**：

| probe | detector（命中即"答不出"） |
|---|---|
| 若这东西明天消失，谁受损？ | 无具体受损方 / 只说"我们" |
| 这个指标能观测吗？基线多少？ | 无基线、无口径、无测量方式 |
| 如果不做，最坏结果是什么？ | 无法量化 / 无法与"做"比较 |

### 3.4 权限分流（D-0030）

| 层 | 谁 | 管什么 | 打断你吗 |
|---|---|---|---|
| L-auto | 判据 + 脚本 | 日常执行、算术终审、审计 L1/L2 | 否 |
| L-propose | AD-01 / 判据 | L3 前提命中、终止提议、价值降级、剪枝 | 否，进待裁队列 |
| **L-final** | **你** | 对上述一切的否决权；不可逆动作事前批 | **仅不可逆时打断** |

- 日常产出：**默认通过，24h 内可否决**；超时视为接受。
  - ⚠️ **2026-10-23 实测：该机制无实现载体**。33 轮的 `verdict-layered.json` 里 `veto_deadline` **0 处存在**（32 个文件逐个 grep），`params` 只有 `veto_window_hours: 24`，**无任何脚本读取它、也无扫描器**——「超时视为接受」目前是文档约定，不是可执行规则。两条出路见 **§11 待你定**。
- 终止提议：只提议，不裁则继续跑（不停摆）。
- 不可逆动作（删除/覆盖/对外发送）：**事前必须你批**。
