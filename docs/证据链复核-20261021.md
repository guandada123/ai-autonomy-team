## 一 逐条复核（均可复现）

### 1.1 算术对照：T-13 的差异是「单席不合规」，不是「口径不同」

`docs/单席对照实验-20261021.md` 把 T-13 的差异写成「不是算错，是分类归属不同，两字段之和均 14440」。

但 r18 的人签口径是 `ADJ-001 = count`：

```bash
python3 -c "import json;print(json.load(open('migration-package/runs/round18/adjudication-record.json'))['decisions'])"
# → [{'id':'ADJ-001','chosen':'count',...}, {'id':'ADJ-002','chosen':'6',...}]
```

`count` 的 `implies` 是 `amount_diff_total = 14440`。单席给的是 **13920**（把 520 放进 `excluded`）。
按**已签字的裁决口径**，这是不合规，不是「另一种同样正确的口径」。

**修正**：n=4 的真实结果是 **3 平 1 胜（六席胜）**。「六席不优于单席」这个结论方向反了。

### 1.2 判断层：六席并不比单席更「自洽」

`docs/单席对照实验-20261021.md` §七 的核心论据是：
单席「ADJ 答 `count` 却把 520 归入 `excluded`」→ 自相矛盾且无机制发现；
六席「`amount_diff_total=14440` 与 `ADJ-001=count` 自洽」。

实测三席（`runs/round18/EX-0*.json`）：

| 席位 | 声明 stance | 算术 amount / excluded | 是否自洽 |
|---|---|---|---|
| EX-01 | `ADJ-001 = count` | **13920 / 520** | ❌ 与自身声明相反 |
| EX-02 | `ADJ-001 = count` | 14440 / 0 | ✅ |
| EX-03 | `ADJ-001 = count` | **13920 / 520** | ❌ 与自身声明相反 |

**三席全部声明 `count`，其中两席的算术按 `exclude` 落。** 这与单席的行为完全同型。
差别不在机制，而在**只有单席被拿去和 ADJ 答案对照过**。

全库扫描（`archive/.../exp-blank2/seat_consistency_scan.py`）：

```
可判定「席位×轴」对：86
  算术与自身声明冲突：39 → 45.3%
  按声明选项：exclude 35 ｜ count 4
  按席位：    EX-02 20 ｜ EX-03 11 ｜ EX-01 8
```

**45.3% 的席位产出与其自身声明不符，从未被任何检查发现。**

### 1.3 「20/20 口径条款命中」是生成器保证的

```bash
grep -n "仅单侧存在\|单侧缺失时取整笔" scripts/make_tasks_20.py
# 538 / 544 / 564 —— 四类条款写死在 TASK.md 模板里
```

20 个任务的 TASK.md 在这些条款上**逐字相同**（T-01/04/13/19 各命中 1 处，措辞一致）。
因此「覆盖全部 20 任务，不是 4 个样本的偶然」是把**模板属性**说成了**经验发现**——信息量为 0。

### 1.4 「26:0 是本次研究最硬的一组证据」不成立

三个问题叠加：

1. **只校验 `implies` 字段**：`scripts/check_consistency.py` 全文不含 `excluded_categories`（`grep -n excluded_categories` 零命中）。
2. **只扫聚合层**：扫的是 26 份 `answer-final.json`，不是 132 份席位产出。
3. **该层数值由签字反填**：`answer-final` 的金额是在人签 `count` 之后按 `implies` 落定的，因此必然等于 `implies`。

**在人签之后、在被反填过的产物上，验「声明与算术是否一致」，是构造性通过。**

而聚合层本身就有字段级矛盾（r18/T-13）：

```
amount_diff_total      = 14440.0   ← 含股息入账 520（T101+T103，已逐单号核算）
excluded_categories    = ["单侧仅交割单·股息入账（非交易性现金流）"]
```

TASK.md 把该字段定义为「被**排除在金额差异之外**的类别名列表」。金额里含这 520，类别却声明被排除——两者互斥。
`check_consistency.py` 不读该字段，所以放过。

> 顺带：历史席位产出普遍**没有** `fee_diff_total` 字段（v3.0 才新增，只回填了 answer-final），
> 所以该检查即便改到席位层也跑不动——这是「检查覆盖不到」的第二层原因。

> **39 处冲突的构成（2026-10-21 追加澄清，见 `D-0027`）**：
> 它们**不是**同一个原因，修 implies 也修不掉——
> ① 一部分是 `exclude` 的 `implies` 算错（用注入 id 求和，漏了自然发生的单侧记录，T-13 记成 380/14060）；
> ② 主体是**席位偏离了明写条款**：`TASK.md` §D 明确「仅单侧存在的单号亦为差异单号」，覆盖全部单侧单号，
> 而席位自造「非交易性现金流」子类、只移出股息、保留新股中签（13920/520）。
> ① 已修（`D-0027`，照契约做即通过）；② **不改契约**——加档等于为偏离行为改规则，且 29/29 签字从未选过 `exclude`。
> 修完 ① 后冲突数仍为 **39/86**，但性质已从「无法达成」变为「**可判定的偏离**」。

## 二 补充实验：彻底留白（本轮新做）

### 2.1 原留白实验只留了一半白

```bash
diff migration-package/fixtures/tasks/T-13/TASK.md \
     archive/2026-10-21-conversation/backups/exp-blank/T-13/TASK.md

```

`fee_diff_total` 行的「单侧缺失时取整笔费用」仍在，而 D-0025 自己把它列为三条约束之一。
**被删掉的只是三条约束里的一条，另两条原封不动** → 当然推出唯一解。

### 2.2 本轮做法

同时删掉两处线索，派 3 个互不可见的单席（各自独立目录，禁读目录外路径）：

```
/tmp/exp-blank2/t13-{a,b,c}/  ← 只有 TASK.md + ledger.csv + bill.csv
```

### 2.3 结果

| 席 | amount_diff_total | excluded_amount_total | fee_diff_total |
|---|---|---|---|
| A | 14440 | 0 | **0.03** |
| B | 14440 | 0 | **5.17** |
| C | 14440 | 0 | **0.03** |

- **amount 分桶：3/3 收敛 `count`** → 「勾稽恒等 + 字段语义」确实能夹出金额侧唯一解，文档这条结论**比我预期的更硬**。
- **fee 列：2:1 分裂** → 一旦删掉「单侧缺失取整笔费用」，同一个字段立刻出现两个值。

### 2.4 含义（精确表述）

| 命题 | 判定 |
|---|---|
| 「在契约现有条款下，ADJ 的正确口径唯一」 | ✅ 成立 |
| 「即使删掉条款，勾稽关系仍能唯一确定答案」 | ❌ **不成立**——只能确定金额侧；费用侧随条款消失而分裂 |
| 「ADJ 数学上注定无判断空间」 | ⚠️ 需改写：**不是数学注定，是条款写死**。删掉一条，判断空间立刻出现 |

这个区别很关键：前者说「这类任务永远没有判断项」（那就该砍席位），
后者说「你把判断项写成了条款」（那是契约设计选择，不是任务类的宿命）。

## 三 修正后的准确结论

| 命题 | 修正后 |
|---|---|
| 六席算得更准 | **未证实**（3 平 1 胜，n=4 太小） |
| 六席判断更准 | **未证实**（判断层 n=1，且单席理由质量不低） |
| 六席更自洽 | ❌ **无证据，且反证在场**（席位层 45.3% 声明×算术冲突） |
| 正确口径唯一 | ✅ 成立（但由条款写死，非数学必然） |
| **六席能保住分歧** | ✅ **有实例**：EX-02 的少数派分支（14440/0）正是最终签字口径，而多数派（13920/520）按签字标准是错的 |

最后一条才是六席唯一被实证的独有能力——它同时保留了 3 种分桶，让「多数派算错」这件事**可见**。
单席只会给出一个答案，且没人知道曾有分歧。这正是 `protocol/01` 五条里的「辩论强制保分歧」。

**D-0025 把它当噪声丢掉了。**
