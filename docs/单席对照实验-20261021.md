# 单席对照实验 · 2026-10-21

> 🔴 **2026-10-21 追加注（正文未改，保留原记录）——引用前必读**
> 本文结论已被 `docs/证据链复核-20261021.md` 修正：
> ① **「算术层无差异」→ 实为 3 平 1 胜（六席胜）**；⚠️ **n=4，样本不足以支持「六席更优」**。T-13 那处差异按已签 `ADJ-001=count`，
>    单席的 `amount_diff_total=13920` 属**不合规**（应为 14440），不是「分类归属不同、总量一致」；
> ② **§七「单席答对算错、六席自洽」的对照不成立**——r18 三席全部声明 `count`，其中 EX-01 / EX-03
>    的算术同样按 `exclude` 落（13920/520），与单席**完全同型**；全库 **39/86（45.3%）** 席位产出与自身声明不符；
> ③ 因此「六席的独特价值是自洽性」应改为「**保分歧**」——EX-02 的少数派分支正是最终签字口径。

> 目的：回答扩样草案的核心问题 —— **「多智能体聚合是否优于单 agent 直答」**
> 方式：4 任务 × 单席直答，与同等任务的历史六席产出逐字段对比
> 结论：**算术层无差异（3/4 完全一致，1/4 仅分类归属不同且总量正确）** ⚠️ **已修正为 3 平 1 胜（n=4，不足以立论）——见文首追加注**

## 一、实验设计

| 项 | 设置 |
|---|---|
| 样本 | T-04、T-09、T-13、T-19（T-19 为 holdout） |
| 单席输入 | 仅 `TASK.md` + `ledger.csv` + `bill.csv`，置于 `/tmp/exp-single-agent/` |
| **真值隔离** | 隔离目录内**不存在** `truth.json` 与 `spec/`（实测泄漏文件数 = 0）；prompt 明确禁读项目目录 |
| 单席产出 | 完整 `summary`（11 个算术字段）+ `diffs`，格式依 `TASK.md` §C |
| 对照基准 | **同任务的历史六席 `answer-final.json`**（r24/T-04、r28/T-09、r18/T-13、r33/T-19） |
| 比较维度 | 算术层 11 个字段（不含判断层 ADJ，单席无选项空间可比） |

**为何不用 `truth.expected` 作基准**：`truth.note` 明确写着
「expected 沿用【历史默认口径】，**它不是真值** —— 签署人可另行裁决」。
用它作基准会把「口径差异」误判为「算错」。

## 二、结果

| 任务 | 一致字段 | 差异 |
|---|---|---|
| **T-04** | **11/11** | 无 —— 完全一致 |
| **T-09** | **11/11** | 无 —— 完全一致 |
| **T-13** | 9/11 | `amount_diff_total` 14440 vs **13920**；`excluded_amount_total` 0 vs **520** |
| **T-19** | **11/11** | 无 —— 完全一致 |

### T-13 的差异分析（唯一一处）

**不是算错，是分类归属不同**：

| | 六席 | 单席 |
|---|---|---|
| `diffs` 的 6 个单号 | T099–T104 | T099–T104 —— **完全相同** |
| T102（股数差 520 元）归属 | 计入 `amount_diff_total` | 归入 `excluded_amount_total` |
| 两字段之和 | 14440 + 0 = **14440** | 13920 + 520 = **14440** ✅ |

**总量一致**，差别仅在于「股数差算不算金额差异」——这**正是 ADJ-001 要人裁决的那个问题**
（`count` 全部计入 vs `exclude` 部分排除）。六席取 `count`（历史默认口径），单席自行取了 `exclude`。

> 这恰好说明：**六席机制的设计意图是「口径交人裁决」，而不是「机器算得更准」**。
> 单席也会做同样的判断，只是它**自行拍板且无人复核**。

## 三、结论

### 3.1 直接回答

**在算术正确性上，单 agent 与六席持平。** 4 个任务中 3 个逐字段完全一致，
第 4 个的差异是口径选择而非计算错误，且总量正确。

### 3.2 那六席的价值在哪

本次实验**没有**测到六席的优势，但**测出了它的价值所在**（负向证据）：

| 维度 | 单席 | 六席 |
|---|---|---|
| 算术 | 同等 | 同等 |
| **口径裁决** | **自行拍板，无人复核** | **ADJ-001/002 显式列出选项，由人签字** |
| **可审计性** | 只有一个最终答案，无法回溯「为什么这么算」 | 六席立场 + 翻边记录 + 裁决记录，可追溯 |
| **抗单点偏见** | 一次成稿，错了就是错了 | 多席位独立计算 + 交叉质疑 |

T-13 就是活例：单席选了 `exclude` 口径，**如果这是错的，没有任何机制能发现**；
六席同样可能选错，但它必须把选择摆到人面前签字。

### 3.3 对项目的影响（必须说清）

扩样草案设定的判据是「多智能体聚合是否**优于**单 agent 直答」。
本次 n=4 的结果**倾向于「算术上不优于」**。

但**不能据此否定机制**，因为：
1. 样本仅 **n=4**，扩样草案要求 ≥20 才不是轶事
2. 只比了算术层，**判断层（ADJ）未比** —— 而那才是机制存在的理由
3. 单席只跑一次，**六席有修订轮**（本轮对照的都是首轮产出）

**可下的最小结论**：
> 如果机制的价值主张是「算得更准」，本次实验不支持这一点。
> 它的价值必须落在「口径可裁决 + 过程可审计」上，否则没有存在理由。

## 四、附带发现：修掉一个会让新轮次必然失败的缺陷

做实验准备时发现：**`TASK.md` 里没有 `fee_diff_total` 字段**，而 `spec` 判据要求它。

- 历史 26 份 `answer-final` 能过，是因为该字段**由人工补入**（契约 3.0 落地时统一补齐），
  不是席位按 TASK.md 产出的
- **新轮次若真跑，席位照 TASK.md 做不会带这个字段 → 判据必然 fail**

**已修**：`make_tasks_20.py` 的 TASK.md 模板补入
① JSON 示例中的 `"fee_diff_total": 0`；② 字段表中的定义行（含「单侧缺失取整笔费用」）。
重新生成后 **20/20** 任务的 TASK.md 均含该字段，回归 50/50 复验通过。

**这个缺陷能藏住，是因为「人工补数据」掩盖了「说明文档缺失」** —— 值得记。

## 五、局限（如实标注）

| 局限 | 说明 |
|---|---|
| 样本 n=4 | 远低于扩样草案要求的 ≥20，**只能作信号，不能作结论** |
| 只比算术层 | 判断层 ADJ-001/002 未比（单席无选项空间） |
| 六席为历史产出 | 非本次同时跑，模型版本可能有差异 |
| 单席仅一次 | 无重复测量，无法评估单席自身的方差 |
| 真值隔离靠 prompt | 技术上无法阻止 agent 跨目录读取，依赖其遵守指令；若结果异常好需怀疑 |

## 七、判断层补测（2026-10-21 追加）

算术层证明拉不开差距后，补测**判断层**——那才是六席设计的本意。

### 试点：T-13（唯一算术有差异的任务）

给单席：TASK.md + 数据 + 两个 ADJ 问题与选项 label（**不给 implies、不给「少报不可逆」原则**）。

| 问题 | 单席选择 | 六席/人裁决 | 一致 |
|---|---|---|---|
| ADJ-001（单侧缺失是否计入） | `count` | `count` | ✅ |
| ADJ-002（清单范围） | `6` | `6` | ✅ |

**单席的理由质量不低**，引用了 TASK.md §D「仅单侧存在的单号亦为差异单号」与 `fee_diff_total` 单侧取整笔的条款。

### 但发现了更重要的事：单席内部自相矛盾

| 层面 | T-13 的单席表现 |
|---|---|
| **判断层** | 选 `count`（520 应计入金额差） |
| **算术层**（同一 agent 同一次任务） | 却把 520 归入 `excluded_amount_total`（等于 `exclude` 的效果） |

**它说一套、算另一套，而且没有任何机制让它发现这件事。**

对照六席：`answer-final` 的 `amount_diff_total=14440`（含 520），与 ADJ-001 的 `count` **自洽**；
若不自洽，判据的 `decimal_equals` 会直接 fail（期望 14440，实得 13920）。

### 由此得到的核心结论（修正 §3）

| 假设 | 本次证据 |
|---|---|
| 六席「算得更准」 | ❌ 不支持（3/4 完全一致） |
| 六席「判断更准」 | ❌ 不支持（1/1 一致，且单席理由充分） |
| **六席「判断与算术被强制对齐，且可交叉验证」** | ✅ **有证据**：单席自相矛盾且无法自查；六席的不一致会被判据抓住 |

**机制的价值不在智能，在自洽性与可审计性。**

> 这是本次实验最有用的产出：它把一个模糊的「多智能体是否更好」变成了一个可检验的
> 「同一 agent 的判断与产出是否自洽」——后者能测，前者测不出来。

### 判断层局限

| 项 | 说明 |
|---|---|
| 样本 | **n=1**（仅 T-13 试点），远不足以说「判断层一致」 |
| 提示偏差 | 已告知 6 条差异的类型，可能影响其判断（真实场景需自行识别） |
| 单向性 | 只测了「单席 vs 人」，未测多个单席之间的一致性（那才反映口径的真实歧义度） |

**若要把判断层做成结论，应改成**：同一任务派 **多个独立单席**（如 3 个，互不可见），
看它们之间的一致率 —— 一致率低 = 口径确实歧义，机制有存在理由；一致率高 = 口径是常识。
