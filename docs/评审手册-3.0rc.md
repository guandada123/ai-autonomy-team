## 一、结论（TL;DR）

**可以发布。** 20 个券商对账任务 × 33 轮验证已全部收口，契约从 v2.1 升至 v3.0，回归 50/50、判据自检 27/27。

**但必须知道三条边界**：

1. **v3.0 前后的 spec 不可交叉使用**——判据总数从 13 变 14，历史 verdict 保持 13/13 不改写，用新 spec 重跑历史 answer 得 14/14。引用历史 verdict 时必须标注其 spec 版本，否则 13 与 14 的差异会被误读为失败。
2. **历史轮次的契约版本不会自动升级**——`contract_version` 随轮次不随工具，历史 33 轮仍是 `2.1`（30 轮）/ `2.0`（1 轮）/ 缺失（1 轮）。
3. **`excluded_categories` 是 `diffs[].category` 的派生视图**，必须原样引用，不得在派生层改名（§六.3 有此误判的完整记录）。
4. **「多智能体是否优于单 agent」——原答案已被复核推翻**（原写「不优于」，建立在四组不成立的证据上；见 [`D-0026`](./decisions/D-0026-撤回D-0025核心结论.md)）。
   n=4 算术对照实为 **3 平 1 胜（六席胜）**：T-13 那处差异按已签 `ADJ-001=count`，单席的 13920 属**不合规**，不是「另一种正确口径」。
   判断层「一致」是**错述**：r18 三席全声明 `count`，其中两席算术按 `exclude` 落，与单席同型；全库 **45.3%（39/86）** 席位产出与自身声明不符。
   「26:0 自洽」是**构造性通过**——只校验 `implies`、只扫签字后反填的聚合层、不读 `excluded_categories`；补上该校验后为 **22 通过 / 4 不自洽**。
   **六席唯一被实证的独有能力是「保分歧」**：EX-02 的少数派分支（14440/0）正是最终签字口径，单席只给一个答案且无人知道曾有分歧。
   **边界不变**：这些实验测的是聚合准确性与判断质量，**没有**检验协议五条价值主张（读并行 / 写单线程 / 硬裁判否决 / 软裁判提示 / 保分歧）。
   详见 [`证据链复核`](./证据链复核-20261021.md)（**最新且优先**）、[`单席对照实验`](./单席对照实验-20261021.md)、[`ADJ判断空间分析`](./ADJ判断空间分析-20261021.md)（后二份正文保留，顶部有更正注）。

## 三、六项变更（v2.1 → v3.0）

| # | 变更 | 机器表现 | 回溯影响 |
|---|---|---|---|
| ① | 新增 `summary.fee_diff_total` | `MONEY_PATHS` 成员，需 `decimal_equals` + scale=2 | 无（26 份历史 answer 已补） |
| ② | 三金额字段必须非负 | `E_MONEY_NEGATIVE` → **无条件 fail** | 无（**94 次有值读数**，负值 0 次） |
| ③ | 金额字段必须是 JSON number | `W_MONEY_STRING`；`--strict-money-type` 转 fail | 无（仅警告，历史 5 轮不改判） |
| ④ | 类别枚举 + 空值需说明 | `W_CATEGORY_NOT_ENUM` + `present_or_note` | 无（历史 **45 种**写法仅告警） |
| ⑤ | 日期基准写死 `trade_date` | `truth.rules.date_basis` | 无（口径声明，不改数值） |
| ⑥ | 判据总数 13 → 14 | 算术 10 + 判断物化 4 | 历史 verdict 保持 13/13 |

### 为什么 ① 必须做（一句话）

费用差在旧六字段中无落点，被塞进 `excluded_amount_total`，违反「费用不并入金额」；D-0016 用「两选项 implies 同值」规避，代价是 **9/20 任务的裁决轴失去检验力**——人闸门签字机器无法验证。新字段让它恢复可辨。

### 闭合恒等式（不变）

```
amount_diff_total + excluded_amount_total == raw_total_gap
```

`fee_diff_total` 是**第三维**，不参与该式（费用不属于 total 差）。

| **中性轴** | ADJ 轴两选项 implies 相同，机器无法反推立场 → D-0016 的妥协，已被 ① 解除 |
| **派生视图** | 由其他字段推导而来、必须原样引用原值的字段（如 `excluded_categories`） |
| **`contract_version`** | **随轮次**，不随工具。改 `params.json` 只影响新建轮次 |
