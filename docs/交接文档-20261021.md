## 2. 复核后的准确结论（**最重要，新对话先看这节**）

> 完整证据与复现命令见 `docs/证据链复核-20261021.md`。本节只给结论。

### 2.1 五条结论（修正后）

| 命题 | 判定 | 依据 |
|---|---|---|
| 六席算得更准 | **未证实** | n=4：3 平 1 胜（六席胜）。样本太小，不能写「更优」，也不能写「不优」 |
| 六席判断更准 | **未证实** | 判断层 n=1，且单席理由质量不低 |
| 六席更自洽 | ❌ **无证据，反证在场** | 86 个「席位×轴」可判定对中 **39 对（45.3%）** 席位算术与自身声明冲突 |
| 正确口径唯一 | ✅ **成立** | 彻底留白下 3 席仍收敛（见 §2.4） |
| **六席能保住分歧** | ✅ **有实例** | EX-02 少数派分支正是最终签字口径（见 §2.3） |

### 2.2 四条旧证据的性质（不要再用它们支撑结论）

| 旧证据 | 复核定性 |
|---|---|
| 算术对照 n=4「六席 = 单席」 | ❌ **方向反了**。T-13 那处差异按已签口径 `ADJ-001=count`，单席的 13920 是**不合规**，不是「另一种正确口径」。文档把「总量一致」当等价，等于取消 ADJ 轴的意义 |
| 判断层 n=1「单席选 count，与六席一致」 | ❌ **错述**。r18 三席全声明 `count`，但 EX-01/EX-03 的算术按 `exclude` 落（13920/520），与单席**完全同型** |
| 「20/20 口径条款命中」 | ⚠️ **同义反复**。`make_tasks_20.py` L538/544/564 把条款写死在 TASK.md 模板里，各任务逐字相同 → 模板属性，非经验发现 |
| 「26:0 自洽」 | ❌ **构造性通过**。检查器不含 `excluded_categories`；只扫 answer-final（该层数值签字后按 `implies` 反填）；席位层缺 `fee_diff_total` 跑不动 |

### 2.3 六席唯一被实证的能力：保分歧

r18/T-13 三席同时保留 3 种分桶（14440/0、13920/520、120/14320，均满足 `amount+excluded=raw_gap`）。
其中 **EX-02 的少数派分支（14440/0）正是最终人签口径**，而多数派（13920/520）按签字标准是错的。

**单席只给一个答案，且无人知道曾有分歧。** 这正是 `protocol/01` 五条的「辩论强制保分歧」——
**旧版把它当噪声丢掉了。**

### 2.4 彻底留白实验（本轮新做）

原留白实验只删了 §D 的直答，`fee_diff_total` 行的「单侧缺失时取整笔费用」仍在 —— 而那正是三条约束之一。
同时删掉两处后派 3 个互不可见单席：

| 轴 | 结果 | 含义 |
|---|---|---|
| `amount` 分桶 | **3/3 收敛 14440/0** | 勾稽 + 字段语义确实夹出金额侧唯一解 |
| `fee_diff_total` | **2:1 分裂（5.17 vs 0.03）** | 删掉条款，判断空间立刻出现 |

**准确表述**：不是「数学上注定无判断空间」，而是「**条款把判断项写死了**」。
前者说任务类宿命（可据此砍席位），后者说契约设计选择（砍不得）。

### 2.5 价值边界的准确表述（对外可用）

`protocol/01` 的五条价值主张（读并行 / 写单线程 / 硬裁判否决 / 软裁判提示 / 保分歧）**仍然成立**，
其中「保分歧」本轮**首次拿到正面实例**。

**能说的**：算术正确性上与单席持平；判断正确性上无证据；**但能把分歧保留下来并让人看见**。
**不能说的**：六席更聪明、六席更自洽、六席机制没用——三条都没有证据。

## 9. 一条方法论提醒

本项目最容易犯的错：**把推断当结论**。已发生 7 次（用错基准、没检索就说缺上下文、证伪自己造的稻草人、
把模板属性当经验发现、把「不合规」写成「口径不同」、在反填过的产物上验自洽、读中间态文件下结论）。

**做任何结论前，先问四句**：
1. 我用的**基准**是什么？它是真值还是历史留痕？（`truth.note` 明写「expected 不是真值」）
2. 我要否定/肯定的东西，**定义源**怎么说？（不是我的直觉怎么说）
3. 这个结论**能不能被证伪**？用什么命令能验？
4. 这个**证据是在哪一层、在什么之后**产生的？（签字后反填的产物不能用来验签字前的一致性）
